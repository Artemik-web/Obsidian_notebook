# Vue3 响应式系统

## 1. 什么是响应式

当数据变化时，使用它的地方自动更新（视图自动更新）。

```javascript
let count = 0;
// 页面显示 count
count++;
// 如果是响应式，页面自动更新，不用你手动操作 DOM
```

Vue2 用 `Object.defineProperty`，Vue3 用 ES6 `Proxy`，性能更好，能监听新增属性、删除属性，数组索引变化也能监听。

## 2. 核心 API

### 2.1 ref

定义基本类型响应式数据，也可以定义对象。

```javascript
import { ref } from 'vue';

// 定义
const count = ref(0);
const name = ref('张三');
const user = ref({ name: '张三', age: 18 });

// 取值要 .value
console.log(count.value); // 0

// 赋值也要 .value
count.value++;
user.value.name = '李四';
```

**什么时候用 ref？**
- 基本类型（number string boolean）必须用 ref
- 对象也可以用，推荐简单数据用 ref，复杂对象用 reactive

### 2.2 reactive

定义对象/数组的响应式：

```javascript
import { reactive } from 'vue';

const user = reactive({
  name: '张三',
  age: 18,
  address: {
    city: '北京'
  }
});
const list = reactive([1, 2, 3]);

// 直接用，不用 .value！
user.age++;
user.address.city = '上海';
list.push(4);
```

**reactive 局限性：**
- 不能给基本类型用
- 不能直接解构赋值，会丢失响应性：
  ```javascript
  const user = reactive({ name: '张三', age: 18 });
  let { name } = user; // 解构了，name 现在是普通字符串，不响应了
  ```

解决：用 toRefs 包一下：

```javascript
const user = reactive({ name: '张三', age: 18 });
const { name, age } = toRefs(user);
// name 现在是 ref，响应式保持
// name.value 就是 '张三'
```

### 2.3 toRef / toRefs

**toRef：** 把对象上一个属性转成 ref，保持响应式关联：

```javascript
const user = reactive({ name: '张三', age: 18 });
const nameRef = toRef(user, 'name');
// nameRef.value 就是 '张三'，改它也会影响原对象，保持响应
```

**toRefs：** 把 reactive 对象所有属性都转成 ref，方便解构：

```javascript
import { reactive, toRefs } from 'vue';

function useUser() {
  const user = reactive({
    name: '张三',
    age: 18
  });
  // ... 逻辑 ...
  return toRefs(user);
}

// 组件里用：
const { name, age } = useUser();
// name 和 age 还是响应式 ✓
```

**口诀：解构 reactive 对象，一定要包 toRefs。**

### 2.4 computed 计算属性

根据依赖计算出新值，缓存结果，依赖不变就缓存。

```javascript
import { ref, computed } from 'vue';

const count = ref(0);

// 只读计算属性
const double = computed(() => {
  return count.value * 2;
});
console.log(double.value);

// 可写计算属性
const firstName = ref('张');
const lastName = ref('三');
const fullName = computed({
  get() {
    return firstName.value + ' ' + lastName.value;
  },
 set(val) {
    const parts = val.split(' ');
    firstName.value = parts[0];
    lastName.value = parts[1];
  }
});

fullName.value = '李 四';
// firstName 变成 李，lastName 变成 四
```

**什么时候用：** 需要对现有数据计算得到新值，避免模板里写太多逻辑。

```vue
<template>
  <!-- 好 -->
  <div>{{ doubleCount }}</div>

  <!-- 不好，模板太乱 -->
  <div>{{ count * 2 }}</div>
</template>
```

### 2.5 watch 侦听

监听数据变化，变化了执行回调。

```javascript
import { ref, watch } from 'vue';

const count = ref(0);
const name = ref('张三');

// 监听单个 ref
watch(count, (newVal, oldVal) => {
  console.log(`count 从 ${oldVal} 变成 ${newVal}`);
});

// 监听多个
watch([count, name], ([newCount, newName], [oldCount, oldName]) => {
  console.log('变化了');
});

// 监听对象的属性
const user = reactive({ name: '张三', age: 18 });
watch(() => user.age, (newAge, oldAge) => {
  console.log('年龄变了');
});

// 深度监听（不推荐，尽量不要深度监听，太耗性能）
watch(
  () => user,
  (newUser) => {
    console.log('user 变了');
  },
  { deep: true }
);

// 立即执行（一开始就执行一次）
watch(count, callback, { immediate: true });
```

### 2.6 watchEffect

自动收集依赖，依赖变了就重新执行，不用指定监听谁，自动找。

```javascript
import { ref, watchEffect } from 'vue';

const count = ref(0);
const user = reactive({ name: '张三' });

watchEffect(() => {
  // 这里用到了谁，就监听谁
  console.log(`count is ${count.value}, name is ${user.name}`);
});

// count 变了或者 user.name 变了，自动重新执行
```

**watch vs watchEffect：**
- `watch`：需要明确指定监听谁，只有依赖变了才执行，可以拿到新值旧值
- `watchEffect`：自动收集依赖，适合副作用操作（比如发请求）

例子：根据 id 发请求：

```javascript
const userId = ref(1);

watchEffect(async () => {
  const data = await fetchUser(userId.value);
  user.value = data;
});
// userId 一变，自动重新发请求，完美！
```

### 2.7 readonly 只读

把响应式对象变成只读，防止意外修改：

```javascript
const state = reactive({ count: 0 });
const readonlyState = readonly(state);
// 修改不会生效，会报警告
readonlyState.count++; // ⚠️ 警告
```

一般用在 props 传递过来的数据，或者需要保护的数据不能改。

### 2.8 toRaw 转原始对象

把响应式对象转回普通 JS 对象，很少用：

```javascript
const user = reactive({ name: '张三' });
const raw = toRaw(user);
// raw 就是原始对象，不是响应式
```

## 3. 响应式原理对比

### Vue2 `Object.defineProperty`

问题：
1. 不能监听对象新增属性、删除属性 → 需要 `$set` `$delete`
2. 不能监听数组下标变化 → 要特殊处理，还是有问题
3. 递归遍历所有属性，性能差

### Vue3 `Proxy`

优点：
1. 可以监听新增属性、删除属性
2. 可以监听数组
3. 懒代理，访问到才代理，性能更好
4. 不污染原对象

## 4. 常见坑点

### 坑 1：ref 忘记 .value

```javascript
const count = ref(0);
console.log(count); // 不对，这是 ref 对象
console.log(count.value); // 对，这才是值
```

记住：`<template>` 里不用写 `.value`，模板自动解包，script 里要写。

### 坑 2：解构 reactive 丢失响应性

```javascript
const user = reactive({ name: '张三', age: 18 });
let { name } = user;
name = '李四'; // 改了，视图不更新，因为 name 已经断开了
```

解决：
```javascript
const { name } = toRefs(user);
name.value = '李四'; // ✓ 正常更新
```

### 坑 3：在选项式 API 里解构 setup 返回值也会丢响应性，toRefs 解决。

### 坑 4：响应式对象赋值普通对象会覆盖失去响应

```javascript
let user = reactive({ name: '张三' });
// 错：直接赋值普通对象，响应式没了
user = { name: '李四' };

// 对：改属性
user.name = '李四';

// 或者，如果要整体替换，用 Object.assign
Object.assign(user, { name: '李四', age: 20 });
```

### 坑 5：ref 在模板自动解包，但只在顶层生效

```vue
<!-- 正确，顶层ref自动解包 -->
<template>
  <div>{{ count }}</div> <!-- 不用 count.value -->
</template>

<!-- 如果是对象里面，不会自动解包，要手动写 .value -->
<template>
  <div>{{ userRef.value.name }}</div>
</template>

<script setup>
const userRef = ref({ name: '张三' });
</script>
```

## 5. 最佳实践

1. **基本类型用 ref，对象用 reactive** → 当然全用 ref 也没问题
2. **解构 reactive 一定要用 toRefs**
3. **计算属性要纯函数，不要改依赖**
4. **避免深度 watch，直接监听具体属性更好**
5. **用 watchEffect 发请求，依赖变了自动重新请求**
6. `<script setup>` 里定义的顶层变量可以直接在模板用，不用 return，非常方便


## 总结

- `ref`：定义任意类型响应式，script 取值赋值要 `.value`
- `reactive`：定义对象数组响应式，直接用不用 `.value`
- `toRef/toRefs`：保持响应性，方便解构
- `computed`：计算属性，缓存
- `watch`：监听明确数据变化
- `watchEffect`：自动收集依赖，执行副作用
- Proxy 比 Object.defineProperty 更好，解决了 Vue2 响应式的问题
