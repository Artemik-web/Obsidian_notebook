# Vue3 自定义指令

## 1. 什么是自定义指令

自定义指令用来对 DOM 进行底层操作，封装一些复用的 DOM 操作逻辑。

比如：自动聚焦、按钮权限控制、元素拖拽、点击外部关闭...

## 2. 指令生命周期

Vue3 指令生命周期钩子：

```javascript
const myDirective = {
  // 绑定到元素，只调用一次，指令第一次绑定到元素时
  created(el, binding, vnode, prevVnode) {},
  // 载入父组件之前
  beforeMount(el, binding, vnode, prevVnode) {},
  // 绑定到元素，组件挂载后
  mounted(el, binding, vnode, prevVnode) {},
  // 组件VNode更新前
  beforeUpdate(el, binding, vnode, prevVnode) {},
  // 组件VNode更新后
  updated(el, binding, vnode, prevVnode) {},
  // 元素卸载，只调用一次
  beforeUnmount(el, binding, vnode, prevVnode) {},
  unmounted(el, binding, vnode, prevVnode) {}
}
```

参数说明：
- `el`：指令绑定的 DOM 元素，可以直接操作 DOM
- `binding`：包含指令信息，`binding.value` 是传过来的值，`binding.arg` 是参数
- `vnode`：Vue 编译生成的虚拟节点

## 3. 全局注册

```javascript
// main.js
const app = createApp(App);

// 注册 v-focus
app.directive('focus', {
  mounted(el) {
    el.focus();
  }
});
```

使用：
```vue
<input v-focus>
```

## 4. 局部注册

```vue
<script setup>
// 局部注册，名字就是 v-highlight
const vHighlight = {
  mounted(el, binding) {
    el.style.backgroundColor = binding.value || 'yellow';
  },
  updated(el, binding) {
    el.style.backgroundColor = binding.value || 'yellow';
  }
};
// <script setup> 直接定义就能用，不用注册
</script>

<template>
  <div v-highlight="'red'">高亮文字</div>
</template>
```

## 5. 常用示例

### 示例 1：自动聚焦

```javascript
// 全局注册
app.directive('focus', {
  mounted(el) {
    // 如果是 element-ui 之类的组件包装过，需要 el.querySelector('input')[0]
    const input = el.querySelector('input') || el;
    input.focus();
  }
});
```

使用：
```vue
<input v-focus>
<el-input v-focus></el-input>
```

### 示例 2：点击外部关闭

点击元素外面，触发回调：

```javascript
// v-click-outside="close"
app.directive('click-outside', {
  mounted(el, binding) {
    el.handler = (e) => {
      // 如果点击的是元素本身或者子元素，不触发
      if (!el.contains(e.target)) {
        binding.value(e); // 调用传过来的回调
      }
    };
    document.addEventListener('click', el.handler);
  },
  unmounted(el) {
    document.removeEventListener('click', el.handler);
  }
});
```

使用：
```vue
<div v-click-outside="handleClose">
  下拉框内容
</div>
```

### 示例 3：权限控制

根据权限显示/隐藏：

```javascript
app.directive('permission', {
  mounted(el, binding) {
    const permissions = store.getters['user/permissions'];
    const required = binding.value;
    if (!permissions.includes(required)) {
      el.remove(); // 没有权限删掉
    }
  }
});
```

使用：
```vue
<button v-permission="'user:add'">添加用户</button>
```

### 示例 4：拖拽

```javascript
app.directive('drag', {
  mounted(el) {
    let isDragging = false;

    el.onmousedown = (e) => {
      isDragging = true;
      const startX = e.clientX - el.offsetLeft;
      const startY = e.clientY - el.offsetTop;

      const onMouseMove = (e) => {
        if (!isDragging) return;
        const left = e.clientX - startX;
        const top = e.clientY - startY;
        el.style.position = 'absolute';
        el.style.left = left + 'px';
        el.style.top = top + 'px';
      };

      const onMouseUp = () => {
        isDragging = false;
        document.removeEventListener('mousemove', onMouseMove);
        document.removeEventListener('mouseup', onMouseUp);
      };

      document.addEventListener('mousemove', onMouseMove);
      document.addEventListener('mouseup', onMouseUp);
    };
  }
});
```

使用：
```vue
<div v-drag>可拖拽盒子</div>
```

### 示例 5：带参数的指令

```vue
<div v-color="color">背景色</div>
<!-- 带参数 -->
<div v-background:color="color"></div>
```

```javascript
app.directive('background', {
  mounted(el, binding) {
    if (binding.arg === 'color') {
      el.style.backgroundColor = binding.value;
    }
  }
});
```

## 6. 函数简写

如果 created 和 updated 做一样的事，可以简写：

```javascript
app.directive('color', (el, binding) => {
  el.style.color = binding.value;
});
```

## 7. 最佳实践

- 能不用指令就不用指令，能用组件实现用组件
- 指令主要用于底层 DOM 操作，封装通用 DOM 逻辑
- 记得在 `unmounted` 清理事件监听，防止内存泄漏
- 操作 DOM 一般在 `mounted` 之后

## 总结

- 自定义指令封装底层 DOM 操作
- 生命周期 created/mounted/updated/unmounted
- 全局注册 `app.directive`，局部直接定义在 `<script setup>`
- 常见：自动聚焦、点击外部关闭、权限控制、拖拽...
