# Vue3 基础

## 1. Vue 简介

Vue (发音 /vjuː/，类似 view) 是一套用于构建用户界面的**渐进式框架**。

- 易学易用
- 性能出色，体积小巧
- 生态丰富
- 支持组合式 API（Vue3 推荐）

## 2. 创建项目

### Vite 创建（推荐）

Vite 是下一代前端构建工具，开发体验更好：


## 3. 基本结构

一个 `.vue` 单文件组件（SFC）结构：

```vue
<script setup>
// 逻辑
import { ref } from 'vue';
const message = ref('Hello Vue');
const count = ref(0);
</script>

<template>
  <!-- 模板 -->
  <h1>{{ message }}</h1>
  <button @click="count++">计数: {{ count }}</button>
</template>



<style scoped>
/* 样式，scoped 只作用当前组件 */
h1 {
  color: red;
}
</style>
```

- `<template>`：模板
- `<script>`：逻辑
- `<style>`：样式
- `scoped`：样式只作用当前组件，不污染全局

Vue3 推荐使用 `<script setup>` 语法糖，更简洁。

## 4. 模板语法

### 4.1 插值

```vue
<template>
  <!-- 文本插值 -->
  <p>{{ message }}</p>

  <!-- HTML 插值 -->
  <div v-html="rawHtml"></div>

  <!-- 属性绑定 -->
  <div :id="dynamicId"></div>
  <img :src="imageSrc" alt>

  <!-- 布尔属性 -->
  <button :disabled="isDisabled">按钮</button>

  <!-- 直接写字符串 -->
  <div class="box">...</div>

  <!-- 动态多个属性 -->
  <div v-bind="objectOfAttrs"></div>
</template>
```

### 4.2 指令

指令是以 `v-` 开头的特殊属性：

| 指令        | 作用                      |
| --------- | ----------------------- |
| `v-if`    | 条件渲染                    |
| `v-else`  | else 分支                 |
| `v-show`  | 显示/隐藏（DOM 还在，改 display） |
| `v-for`   | 循环渲染列表                  |
| `v-on`    | 绑定事件，缩写 `@`             |
| `v-bind`  | 绑定属性，缩写 `:`             |
| `v-model` | 双向绑定表单                  |
| `v-once`  | 只渲染一次，不再更新              |
| `v-memo`  | 缓存，只在依赖变化更新             |
| `v-html`  | 渲染 HTML                 |
| `v-text`  | 设置文本内容                  |

### 4.3 条件渲染

```vue
<template>
  <div v-if="type === 'A'">
    A
  </div>
  <div v-else-if="type === 'B'">
    B
  </div>
  <div v-else>
    C
  </div>

  <!-- v-if vs v-show -->
  <div v-show="isShow">内容</div>
</template>
```

**v-if vs v-show：**
- `v-if`：不满足条件，DOM 不会渲染，适合条件不经常变
- `v-show`：只是 display: none，DOM 一直在，适合频繁切换

### 4.4 列表循环

```vue
<template>
  <!-- 循环数组 -->
  <ul>
    <li v-for="(item, index) in list" :key="item.id">
      {{ index }} - {{ item.name }}
    </li>
  </ul>

  <!-- 循环对象 -->
  <ul>
    <li v-for="(value, key, index) in obj">
      {{ key }}: {{ value }}
    </li>
  </ul>

  <!-- 循环数字 -->
  <span v-for="n in 10">{{ n }}</span>
</template>
```

**key 一定要加**，尽量用唯一 id 不要用 index，方便 Vue 复用节点。

### 4.5 事件绑定

```vue
<template>
  <!-- 基本用法 -->
  <button @click="handleClick">点击</button>

  <!-- 传参 -->
  <button @click="handleClick(123)">点击传参</button>

  <!-- 还要事件对象 -->
  <button @click="handleClick(123, $event)">点击</button>

  <!-- 修饰符 -->
  <form @submit.prevent="onSubmit"> <!-- prevent 阻止默认行为 -->
  <a @click.stop="handleClick"> <!-- stop 阻止冒泡 -->
  <div @click.capture> <!-- 捕获阶段 -->
  <div @click.self> <!-- 只当点击自己触发 -->
  <div @click.once> <!-- 只触发一次 -->
  <input @keyup.enter="onEnter"> <!-- 按键修饰符 -->
  <input @keyup.esc="onEsc">
</template>

<script setup>
const handleClick = (num, e) => {
  console.log(num, e);
};
</script>
```

### 4.6 双向绑定 v-model

```vue
<template>
  <!-- 文本 -->
  <input v-model="message" placeholder="输入...">
  <p>输入: {{ message }}</p>

  <!-- 多行文本 -->
  <textarea v-model="message"></textarea>

  <!-- 复选框 -->
  <input type="checkbox" id="checkbox" v-model="checked">
  <label for="checkbox">{{ checked }}</label>

  <!-- 多个复选框 -->
  <input type="checkbox" value="a" v-model="checkedNames">
  <input type="checkbox" value="b" v-model="checkedNames">
  <!-- checkedNames 是数组 -->

  <!-- 单选 -->
  <input type="radio" value="male" v-model="gender">
  <input type="radio" value="female" v-model="gender">

  <!-- 下拉选择 -->
  <select v-model="selected">
    <option disabled value="">请选择</option>
    <option value="a">A</option>
    <option value="b">B</option>
  </select>
</template>

<script setup>
import { ref } from 'vue';
const message = ref('');
const checked = ref(false);
const checkedNames = ref([]);
const gender = ref('male');
const selected = ref('');
</script>
```

**v-model 修饰符：**
- `.trim` 去掉首尾空格
- `.number` 转数字
- `.lazy`  change 事件之后更新，不是 input 实时更新

```vue
<input v-model.trim="text">
<input v-model.number="age">
<input v-model.lazy="msg">
```

### 4.7 缩写

```
v-bind:href → :href
v-on:click → @click
```

### 4.8 类与样式绑定

```vue
<template>
  <!-- 绑定 class -->
  <div :class="{ active: isActive, 'text-danger': hasError }">
  </div>

  <!-- 数组语法 -->
  <div :class="[activeClass, errorClass]">

  <!-- 数组对象混合 -->
  <div :class="[baseClass, { active: isActive }]">

  <!-- 绑定 style -->
  <div :style="{ color: activeColor, fontSize: fontSize + 'px' }">

  <!-- 数组语法多个样式对象 -->
  <div :style="[baseStyles, overridingStyles]">
</template>

<script setup>
const isActive = ref(true);
const hasError = ref(false);
const activeClass = ref('active');
const errorClass = ref('text-danger');
const activeColor = ref('red');
const fontSize = ref(16);
</script>
```

## 5. Options API vs Composition API

### Options API（Vue2 写法）

按选项组织代码：`data`、`methods`、`computed`、`watch`、`created`...

```vue
<script>
export default {
  data() {
    return {
      count: 0
    };
  },
  methods: {
    increment() {
      this.count++;
    }
  },
  computed: {
    double() {
      return this.count * 2;
    }
  }
};
</script>
```

优点：简单好懂，适合简单组件。
缺点：逻辑分散在多个选项，不好复用，大组件难维护。

### Composition API（Vue3 推荐）

按逻辑关注点组织代码，用 `setup`，更好的代码组织和复用。

```vue
<script setup>
import { ref, computed } from 'vue';

const count = ref(0);
const double = computed(() => count.value * 2);

function increment() {
  count.value++;
}
</script>
```

优点：
- 相同逻辑放一起，好维护
- 更好的类型推断
- 更好的逻辑复用（组合式函数）
- 更适合大型项目

现在 Vue3 推荐用 Composition API + `<script setup>`。

## 6. 创建应用入口

```javascript
// main.js
import { createApp } from 'vue';
import App from './App.vue';

const app = createApp(App);

// 挂载
app.mount('#app');

// 全局注册
import MyComponent from './MyComponent.vue';
app.component('MyComponent', MyComponent);

// 全局属性
app.config.globalProperties.$http = axios;
```

## 7. 项目目录结构（Vite 创建）

```
my-vue-app/
├── public/          # 静态资源
├── src/
│   ├── assets/      # 资源（图片、样式等）
│   ├── components/  # 公共组件
│   ├── router/      # 路由配置
│   ├── stores/      # 状态管理（Pinia）
│   ├── views/       # 页面组件
│   ├── App.vue      # 根组件
│   └── main.js      # 入口文件
├── index.html
├── package.json
└── vite.config.js
```

## 总结

- Vue3 推荐用 Vite 创建项目
- 单文件组件 `.vue` 由 template、script、style 组成
- 推荐 `<script setup>` + Composition API
- 模板语法：插值、指令、循环、条件、事件绑定这些和 Vue2 基本一致
- v-model 双向绑定，现在也支持自定义组件使用了
