# Vue 过渡与动画

Vue 提供了 `<Transition>` 和 `<TransitionGroup>` 组件帮你做过渡动画。

## 1. 基本用法

```vue
<template>
  <button @click="show = !show">切换</button>

  <Transition name="fade">
    <p v-if="show">内容</p>
  </Transition>
</template>

<script setup>
import { Transition } from 'vue';
import { ref } from 'vue';
const show = ref(true);
</script>

<style>
.fade-enter-active,
.fade-leave-active {
  transition: opacity 0.3s ease;
}

.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}
</style>
```

## 2. 过渡类名

| 类名 | 说明 |
|------|------|
| `xxx-enter-from` | 进入开始，动画开始前 |
| `xxx-enter-active` | 进入过程，整个进入阶段都有 |
| `xxx-enter-to` | 进入结束 |
| `xxx-leave-from` | 离开开始 |
| `xxx-leave-active` | 离开过程 |
| `xxx-leave-to` | 离开结束 |

命名：`name="fade"` → 类名 `fade-xxx`

## 3. CSS 动画示例

```vue
<Transition name="bounce">
  <div v-if="show" class="box"></div>
</Transition>

<style>
.bounce-enter-active {
  animation: bounce-in 0.5s;
}
.bounce-leave-active {
  animation: bounce-in 0.5s reverse;
}
@keyframes bounce-in {
  0% {
    transform: scale(0);
  }
  50% {
    transform: scale(1.2);
  }
  100% {
    transform: scale(1);
  }
}
</style>
```

## 4. 自定义过渡类名

配合 animate.css 用：

先装：
```bash
npm install animate.css
```

用：
```vue
<template>
  <Transition
    name="fade"
    enter-from-class="animate__animated animate__fadeIn"
    leave-to-class="animate__animated animate__fadeOut"
  >
    <div v-if="show">内容</div>
  </Transition>
</template>

<style>
@import "animate.css/animate.min.css";
</style>
```

## 5. 动态切换多个元素

```vue
<template>
  <Transition name="fade">
    <div :key="show">
      {{ show ? 'on' : 'off' }}
    </div>
  </Transition>
</template>
```

**多个元素切换要加 key，Vue 才能区分。**

## 6. 同时进入离开同时进行

默认是先出后进，要同时进行设置 `mode="out-in"`：

```vue
<Transition mode="out-in">
  <!-- out-in：先出后进，默认 in-out 先进后出 -->
  <component :is="currentView"></component>
</Transition>
```

mode:
- `in-out`：新元素先进入，再旧元素离开（默认）
- `out-in`：旧元素先离开，再新元素进入

## 7. 列表过渡 `<TransitionGroup>`

v-for 列表的过渡：

```vue
<template>
  <TransitionGroup tag="ul" name="list">
    <li v-for="item in items" :key="item.id">
      {{ item.text }}
    </li>
  </TransitionGroup>
</template>

<style>
.list-enter-active,
.list-leave-active {
  transition: all 0.5s;
}
.list-enter-from,
.list-leave-to {
  opacity: 0;
  transform: translateX(30px);
}
/* 移动的时候也有动画 */
.list-move {
  transition: transform 0.5s;
}
</style>
```

- `tag`：渲染成什么标签，默认 span
- `list-move`：排序移动时的过渡

## 8. JavaScript 钩子

可以完全用 JS 写动画，配合 GSAP 之类的库：

```vue
<template>
  <Transition
    @before-enter="beforeEnter"
    @enter="enter"
    @after-enter="afterEnter"
    @before-leave="beforeLeave"
    @leave="leave"
    @after-leave="afterLeave"
  >
    <div v-if="show">内容</div>
  </Transition>
</template>

<script setup>
import gsap from 'gsap';

const beforeEnter = (el) => {
  el.style.opacity = 0;
};
const enter = (el, done) => {
  gsap.to(el, {
    opacity: 1,
    duration: 0.5,
    onComplete: done
  });
};
const leave = (el, done) => {
  gsap.to(el, {
    opacity: 0,
    duration: 0.5,
    onComplete: done
  });
};
</script>
```

钩子：
- `before-enter` → `beforeEnter(el)`
- `enter` → `enter(el, done)` 动画结束调用 done
- `after-enter` → `afterEnter(el)`
- `before-leave` → `beforeLeave(el)`
- `leave` → `leave(el, done)`
- `after-leave` → `afterLeave(el)`

## 9. 出现动画

第一次渲染就播放动画：

```vue
<Transition appear>
  <div v-if="show">...</div>
</Transition>
```

`appear` 属性让第一次渲染也有过渡。

## 10. 路由过渡

```vue
<template>
  <Transition name="fade" mode="out-in">
    <router-view />
  </Transition>
</template>

<style>
.fade-enter-active,
.fade-leave-active {
  transition: opacity 0.3s;
}
.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}
</style>
```

每个路由切换都有淡入淡出效果。

## 11. 常见动画效果

### 淡入淡出

```css
.fade-enter-active,
.fade-leave-active {
  transition: opacity 0.3s ease;
}
.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}
```

### 滑入滑出（从上到下）

```css
.slide-down-enter-active,
.slide-down-leave-active {
  transition: transform 0.3s ease, opacity 0.3s;
}
.slide-down-enter-from {
  opacity: 0;
  transform: translateY(-10px);
}
.slide-down-leave-to {
  opacity: 0;
  transform: translateY(10px);
}
```

### 缩放

```css
.zoom-enter-active,
.zoom-leave-active {
  transition: transform 0.3s ease, opacity 0.3s;
}
.zoom-enter-from {
  opacity: 0;
  transform: scale(0.8);
}
.zoom-leave-to {
  opacity: 0;
  transform: scale(1.2);
}
```

## 总结

- `<Transition>` 做单个元素/组件进入离开过渡
- `<TransitionGroup>` 做 v-for 列表过渡
- 可以用 CSS transition/animation，也可以用 JS 配合动画库
- `mode` 控制进出顺序，`appear` 控制初始渲染动画
- 配合 animate.css 快速做漂亮动画
- 路由过渡直接包一层 `<Transition>` 就好了
