# JavaScript 对象与函数进阶

## 1. 对象

对象是键值对的集合，用来描述一个事物的多个属性。

### 1.1 创建对象

```javascript
// 字面量方式（推荐）
let person = {
  name: '张三',
  age: 18,
  gender: '男',
  sayHi: function() {
    console.log('你好，我是' + this.name);
  }
};

// 构造函数方式
let person = new Object();
person.name = '张三';
person.age = 18;

// 构造函数创建多个对象
function Person(name, age) {
  this.name = name;
  this.age = age;
  this.sayHi = function() {
    console.log('Hi');
  };
}
let p1 = new Person('张三', 18);
let p2 = new Person('李四', 20);
```

### 1.2 访问属性

```javascript
// 点语法（常用）
console.log(person.name); // 张三
person.age = 19; // 修改

// 方括号语法（键是变量/特殊字符/数字的时候用）
console.log(person['age']); // 19
let key = 'name';
console.log(person[key]); // 张三 → 用变量必须方括号

// 调用方法
person.sayHi();
```

### 1.3 删除属性

```javascript
delete person.age;
```

### 1.4 检查属性是否存在

```javascript
'name' in person; // true → 自己或原型链上有就 true
person.hasOwnProperty('name'); // true → 只有自己的属性才 true
```

### 1.5 遍历对象

```javascript
// for in 遍历对象所有可枚举属性
for (let key in person) {
  console.log(key);       // 属性名
  console.log(person[key]); // 属性值
}
```

### 1.6 简写（ES6）

```javascript
let name = '张三';
let age = 18;
// 属性简写
let person = {
  name, // 等价于 name: name
  age,  // 等价于 age: age
  // 方法简写
  sayHi() {
    console.log(this.name);
  }
};
```

### 1.7 计算属性名（ES6）

```javascript
let prop = 'name';
let person = {
  [prop]: '张三' // 属性名是变量的值
};
console.log(person.name); // 张三
```

### 1.8 解构赋值（ES6）

```javascript
// 对象解构
let person = { name: '张三', age: 18 };
let { name, age } = person;
console.log(name); // 张三
console.log(age); // 18

// 重命名
let { name: myName } = person;
console.log(myName); // 张三

// 默认值
let { gender = '未知' } = person;
console.log(gender); // 未知

// 数组解构
let arr = [1, 2, 3];
let [a, b, c] = arr;
console.log(a, b, c); // 1 2 3

// 交换变量
[a, b] = [b, a];
```

## 2. this 指向

this 指向谁，看**函数怎么调用**，不是看定义在哪里。

| 调用方式 | this 指向 |
|----------|-----------|
| 普通函数调用 | `window`（浏览器） / `global`（Node） / 严格模式 `undefined` |
| 对象方法调用 | 指向该对象 |
| 构造函数调用 | 指向新创建的实例 |
| 箭头函数 | 继承外层作用域的 this |
| call/apply/bind | 可以指定 this |

例子：

```javascript
// 1. 普通函数
function foo() {
  console.log(this);
}
foo(); // window

// 2. 对象方法
let obj = {
  name: 'obj',
  fn: function() {
    console.log(this);
  }
};
obj.fn(); // obj

// 3. 构造函数
function Person(name) {
  this.name = name; // this 指向 new 出来的实例
}
let p = new Person('张三');

// 4. 箭头函数
let arrow = {
  name: 'arrow',
  say: () => {
    console.log(this);
  }
};
arrow.say(); // 外层的 this，这里是 window
```

## 3. 改变 this 指向

### 3.1 call

```javascript
func.call(thisArg, arg1, arg2, ...);
// 立即执行，传参用逗号分隔
```

例子：
```javascript
function intro(age, gender) {
  console.log(`${this.name}, ${age}, ${gender}`);
}
let person = { name: '张三' };
intro.call(person, 18, '男');
// this → person，输出：张三, 18, 男
```

### 3.2 apply

```javascript
func.apply(thisArg, [argsArray]);
// 立即执行，参数用数组传
```

例子：求数组最大值：
```javascript
let arr = [5, 2, 9, 1];
let max = Math.max.apply(Math, arr);
console.log(max); // 9
```

### 3.3 bind

```javascript
let newFunc = func.bind(thisArg, arg1, arg2...);
// 不立即执行，返回新函数，新函数的 this 已经绑定好了
```

例子：绑定后用：

```javascript
let person = { name: '张三' };
function greet() {
  console.log(`你好 ${this.name}`);
}
let greetPerson = greet.bind(person);
greetPerson(); // 你好 张三 → this 已经固定了
```

**三者区别：**
- `call` / `apply`：立即执行，一次调用就绑定一次
- `bind`：不立即执行，生成新函数，以后调用都是绑定好的 this

## 4. 闭包

### 4.1 什么是闭包

函数 A 里面嵌套了函数 B，B 引用了 A 的变量，然后把 B 返回出去，外部就访问到了 A 的变量，这就形成了闭包。

```javascript
function createCounter() {
  let count = 0; // 这个变量在函数内部，外面本来访问不到
  return {
    increment: function() {
      count++;
    },
    getCount: function() {
      return count;
    }
  };
}

let counter = createCounter();
counter.increment();
counter.increment();
console.log(counter.getCount()); // 2 → 访问到了内部变量 → 闭包
```

### 4.2 闭包作用

- 隐藏变量，不污染全局
- 可以保存变量，函数执行完变量不销毁
- 模块化开发

### 4.3 缺点

- 闭包变量不会被垃圾回收，滥用可能导致内存泄漏
- 合理使用没问题

## 5. 立即执行函数 IIFE

```javascript
(function() {
  // 独立作用域，里面变量外面访问不到
  // 执行完自动销毁
})();

// 传参
(function(window, document) {
  // 代码
})(window, document);
```

作用：隔离作用域，不污染全局。现在 ES6 模块出来了，用模块就好了。

## 6. 深浅拷贝

基本类型拷贝没问题，引用类型拷贝要分深浅。

### 6.1 浅拷贝

只拷贝引用，指向同一个对象，改了会互相影响。

```javascript
// 浅拷贝方法：

// 1. Object.assign
let obj = { a: 1, b: { c: 2 } };
let newObj = Object.assign({}, obj);

// 2. 展开运算符（推荐）
let newObj = { ...obj };

// 3. 数组浅拷贝
let arr = [1, 2, 3];
let newArr = [...arr];
let newArr2 = arr.slice();
let newArr3 = arr.concat();
```

浅拷贝只拷贝一层，如果属性还是对象，那还是引用。

### 6.2 深拷贝

拷贝所有层级，完全是新对象，改了不影响原对象。

**方法 1：JSON 序列化反序列化（简单对象可用）**
```javascript
let obj = { a: 1, b: { c: 2 } };
let newObj = JSON.parse(JSON.stringify(obj));
obj.b.c = 100;
console.log(newObj.b.c); // 2 → 不影响 ✓

// 缺点：不能处理函数、正则、Date、循环引用
```

**方法 2：递归深拷贝（自己写）**
```javascript
function deepClone(obj, cache = new WeakMap()) {
  if (obj === null) return null;
  if (typeof obj !== 'object') return obj;
  if (obj instanceof Date) return new Date(obj);
  if (obj instanceof RegExp) return new RegExp(obj);
  // 处理循环引用
  if (cache.has(obj)) return cache.get(obj);
  let clone = new obj.constructor();
  cache.set(obj, clone);
  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      clone[key] = deepClone(obj[key], cache);
    }
  }
  return clone;
}
```

**方法 3：使用 lodash 的 cloneDeep（项目中推荐）**
```javascript
import cloneDeep from 'lodash/cloneDeep';
let newObj = cloneDeep(obj);
```

## 7. 箭头函数

- 语法更简洁
- this 继承外层作用域的 this，自己没有 this
- 不能当构造函数，不能 new
- 没有 arguments

```javascript
// 普通函数 vs 箭头函数
let arr = [1, 2, 3];
let doubled = arr.map(function(n) {
  return n * 2;
});
// 箭头简写
let doubled = arr.map(n => n * 2);

// this 例子
let button = document.getElementById('btn');
button.addEventListener('click', function() {
  // this → button
  setTimeout(() => {
    // 箭头 this 继承外层，所以还是 button
    this.style.backgroundColor = 'red';
  }, 1000);
});

// 如果不用箭头，要保存 this：
// let that = this;
// 箭头省了这一步
```

**什么时候用箭头：** 回调函数、简单函数、需要继承 this 的时候
**什么时候不用：** 对象方法、构造函数、需要 arguments 的时候

## 8. 剩余参数与扩展运算符

### 8.1 剩余参数 `...`

收集剩余参数到数组：

```javascript
// 代替 arguments
function sum(...nums) {
  return nums.reduce((a, b) => a + b, 0);
}
console.log(sum(1, 2, 3, 4)); // 10

// 收集剩余
function fn(a, b, ...rest) {
  console.log(a); // 1
  console.log(b); // 2
  console.log(rest); // [3, 4, 5] → 剩下的都在这里
}
fn(1, 2, 3, 4, 5);
```

### 8.2 扩展运算符 `...`

展开数组/对象：

```javascript
// 展开数组
let arr1 = [1, 2, 3];
let arr2 = [4, 5, 6];
let merged = [...arr1, ...arr2]; // [1,2,3,4,5,6]

// 展开对象
let obj1 = { a: 1, b: 2 };
let obj2 = { ...obj1, c: 3 }; // {a:1, b:2, c:3}
// 覆盖属性
let obj = { a: 1, b: 2 };
let newObj = { ...obj, b: 3 }; // {a:1, b:3}
```

## 9. 原型与继承

### 9.1 原型是什么

每个函数都有 `prototype` 属性，指向原型对象。
每个实例都有 `__proto__` 属性，指向构造函数的 prototype。
`constructor` 原型对象指向构造函数。

关系：
```
构造函数.prototype → 原型对象
实例.__proto__ → 原型对象
原型对象.constructor → 构造函数
```

找属性/方法的时候，实例找不到，就去 `__proto__` 找，一层层往上就是原型链。

### 9.2 原型继承经典写法

```javascript
// 父构造函数
function Person(name) {
  this.name = name;
}
Person.prototype.sayHi = function() {
  console.log(this.name);
};

// 子构造函数
function Student(name, grade) {
  Person.call(this, name); // 继承属性
  this.grade = grade;
};
// 继承方法
Student.prototype = Object.create(Person.prototype);
Student.prototype.constructor = Student;
// 添加子类方法
Student.prototype.study = function() {
  console.log('study');
};
```

现在 ES6 class 语法更清晰：

```javascript
class Person {
  constructor(name) {
    this.name = name;
  }
  sayHi() {
    console.log(this.name);
  }
}

class Student extends Person {
  constructor(name, grade) {
    super(name); // 调用父构造
    this.grade = grade;
  }
  study() {
    console.log('study');
  }
}
```

## 10. 模块化

### 常见模块化规范

- **CommonJS**（Node.js）：`require('./module')`，`module.exports = ...`
- **ES 模块化**（浏览器推荐）：`import` / `export`

```javascript
// ES 模块化写法

// utils.js 导出
export function add(a, b) {
  return a + b;
}
export default {
  name: 'utils'
};

// 导入
import { add } from './utils.js';
import utils from './utils.js';
```

## 总结

核心要点：
1. 对象字面量创建，解构赋值方便取属性
2. this 看调用方式，箭头函数继承外层 this
3. call/apply/bind 可以改 this
4. 闭包保存内部变量，隐藏作用域
5. 深浅拷贝注意区别，深拷贝要递归处理
6. ES6 class 语法比原型继承更清晰
