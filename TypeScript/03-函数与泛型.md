# TypeScript 函数与泛型

## 1. 函数类型

### 1.1 函数声明

```typescript
// 给参数和返回值加类型
function add(x: number, y: number): number {
  return x + y;
}

// 没有返回值写 void
function log(message: string): void {
  console.log(message);
}

// 永远不返回 never
function throwError(message: string): never {
  throw new Error(message);
}
```

### 1.2 函数表达式

```typescript
// 完整写法
const add: (x: number, y: number) => number = function(x, y) {
  return x + y;
};

// 或者用类型别名
type AddFunc = (x: number, y: number) => number;
const add: AddFunc = function(x, y) {
  return x + y;
};
```

### 1.3 接口描述函数

```typescript
interface SearchFunc {
  (source: string, keyword: string): boolean;
}

const search: SearchFunc = function(src, kw) {
  return src.includes(kw);
};
```

### 1.4 参数默认值

```typescript
function add(x: number, y: number = 0): number {
  return x + y;
}

add(5); // y = 0
```

### 1.5 可选参数

```typescript
function buildName(first: string, last?: string): string {
  if (last) {
    return `${first} ${last}`;
  }
  return first;
}

buildName('Zhang');
buildName('Zhang', 'San');
```

**可选参数必须放在最后。**

### 1.6 剩余参数

```typescript
function sum(...nums: number[]): number {
  return nums.reduce((a, b) => a + b, 0);
}

sum(1, 2, 3); // 6
```

### 1.7 重载

同一个函数可以接受不同参数，返回不同类型，给多个函数签名：

```typescript
// 重载列表
function reverse(x: number): number;
function reverse(x: string): string;

// 实现
function reverse(x: number | string): number | string {
  if (typeof x === 'number') {
    return Number(x.toString().split('').reverse().join(''));
  } else {
    return x.split('').reverse().join('');
  }
}

reverse(123); // 321 返回 number
reverse('abc'); // 'cba' 返回 string
```

重载只有 TS 用，编译后还是一个函数，只是给 TS 看类型。

## 2. 泛型是什么

泛型就是**让类型也能接受参数**，同一个函数可以支持多种类型，不写 any，又能保持类型安全。

例子：创建一个函数，输入什么类型，返回什么类型。

不用泛型：
```typescript
// 写法一：any，丢失类型，不知道输入输出什么类型
function identity(arg: any): any {
  return arg;
}

// 写法二：泛型
function identity<T>(arg: T): T {
  return arg;
}
```

`T` 就是类型参数，调用的时候会自动推断：

```typescript
// 自动推断 T 是 number
let output = identity(123); // output 类型 number

// 也可以指定
let output = identity<string>("hello"); // output 类型 string
```

## 3. 泛型基本用法

### 泛型函数

```typescript
function createArray<T>(length: number, value: T): T[] {
  let result: T[] = [];
  for (let i = 0; i < length; i++) {
    result.push(value);
  }
  return result;
}

let strings = createArray<string>(3, 'hello');
// strings 类型是 string[]
```

### 泛型接口

```typescript
interface GenericIdentityFn<T> {
  (arg: T): T;
}

function identity<T>(arg: T): T {
  return arg;
}

let myIdentity: GenericIdentityFn<number> = identity;
```

泛型类：

```typescript
class GenericNumber<T> {
  zeroValue: T;
  add: (x: T, y: T) => T;
  constructor(zero: T, addFn: (x: T, y: T) => T) {
    this.zeroValue = zero;
    this.add = addFn;
  }
}

let g = new GenericNumber<number>(0, (x, y) => x + y);
```

## 4. 泛型约束

限制 T 必须满足什么条件，必须有哪些属性：

```typescript
interface Lengthwise {
  length: number;
}

function loggingIdentity<T extends Lengthwise>(arg: T): T {
  // 现在可以用 .length 了，因为 T 一定有 length
  console.log(arg.length);
  return arg;
}

loggingIdentity([1, 2, 3]); // OK
loggingIdentity('abc'); // OK
loggingIdentity(123); // ❌ number 没有 length
```

### 泛型约束用 keyof

```typescript
function getProperty<T, K extends keyof T>(obj: T, key: K) {
  return obj[key];
}

let obj = { a: 1, b: 2 };
getProperty(obj, 'a'); // OK，类型正确
getProperty(obj, 'c'); // ❌ 'c' 不是 obj 的键
```

非常实用，类型检查帮你检查键名对不对。

## 5. 泛型默认类型

```typescript
interface A<T = string> {
  value: T;
}

let a: A; // 等价于 A<string>
let b: A<number>; // 指定 number
```

## 6. 常用泛型工具类型

### `Partial<T>` 把 T 的所有属性变成可选

```typescript
// 定义
type Partial<T> = {
  [P in keyof T]?: T[P];
};

// 使用
interface User {
  name: string;
  age: number;
}

// 所有属性都可选
type PartialUser = Partial<User>;
// 等价于
// {
//   name?: string;
//   age?: number;
// }
```

### `Required<T>` 把 T 的所有属性变成必填

```typescript
type Required<T> = {
  [P in keyof T]-?: T[P];
  // -? 去掉可选
};
```

### `Readonly<T>` 所有属性只读

```typescript
type Readonly<T> = {
  readonly [P in keyof T]: T[P];
};
```

### `Pick<T, K>` 从 T 挑几个属性出来

```typescript
type Pick<T, K extends keyof T> = {
  [P in K]: T[P];
};

interface User {
  name: string;
  age: number;
  email: string;
}

type UserNameAndEmail = Pick<User, 'name' | 'email'>;
// 只有 name 和 email
```

### `Omit<T, K>` 从 T 去掉 K 这些属性

```typescript
type Omit<T, K extends keyof any> = Pick<T, Exclude<keyof T, K>>;

interface User {
  name: string;
  age: number;
  email: string;
}

type UserWithoutAge = Omit<User, 'age'>;
// name, email 留下，去掉 age
```

### `Exclude<T, U>` 从 T 去掉 U 包含的类型（联合类型）

```typescript
type T = 1 | 2 | 3;
type U = 2 | 3;
type R = Exclude<T, U>; // 1
```

### `Extract<T, U>` 从 T 提取和 U 交集

```typescript
type T = 1 | 2 | 3;
type U = 2 | 3 | 4;
type R = Extract<T, U>; // 2 | 3
```

### `ReturnType<T>` 获取函数返回类型

```typescript
function foo() {
  return 123;
}

type FooReturn = ReturnType<typeof foo>; // number
```

### `Parameters<T>` 获取函数参数类型组成的元组

```typescript
function foo(a: number, b: string) {
}

type Params = Parameters<typeof foo>; // [number, string]
```

## 7. 什么时候用泛型

- 函数/组件会处理多种类型的数据
- 保持类型安全，不用 any
- 减少重复代码，一个函数支持多种类型

**常用场景：**
- 工具函数，比如 createArray 可以创建任何类型数组
- React/Vue 组件 props，支持多种类型
- 自定义 hook，返回正确的类型
- 容器数据结构，比如链表、树，节点可以是任何类型

## 总结

- 函数要给参数、返回值写类型
- 泛型让类型参数化，一份代码支持多种类型还保持类型安全
- `T extends xxx` 泛型约束，限制类型
- 内置工具类型 `Partial` `Pick` `Omit` `ReturnType` 这些非常实用，开发经常用
- 用好泛型，类型系统帮你做很多事
