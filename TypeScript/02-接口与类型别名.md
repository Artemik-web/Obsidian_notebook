# TypeScript 接口与类型别名

## 1. 接口 interface

接口用来**描述对象的形状**，告诉 TS 这个对象有哪些属性、类型是什么。

### 1.1 基本用法

```typescript
interface User {
  name: string;
  age: number;
}

const user: User = {
  name: '张三',
  age: 18
};
```

### 1.2 可选属性 `?`

属性不一定存在，加 `?`：

```typescript
interface User {
  name: string;
  age?: number; // 年龄可选
}

const user: User = {
  name: '张三'
  // 不写 age 也没问题
};
```

### 1.3 只读属性 `readonly`

初始化之后不能改：

```typescript
interface User {
  readonly id: number;
  name: string;
}

const user: User = {
  id: 1,
  name: '张三'
};

user.id = 2; // 错误！只读不能改
```

### 1.4 任意属性

允许加任意其他属性：

```typescript
interface User {
  name: string;
  age: number;
  [key: string]: any; // 任意 string 键，值任意类型
}

// 现在可以加其他属性
const user: User = {
  name: '张三',
  age: 18,
  email: 'zhangsan@example.com', // 没问题
  address: '北京' // 也没问题
};
```

语法：
```typescript
[propName: string]: any;
// propName 是变量名，可以随便起，类型必须是 string/number/symbol
```

**注意：** 如果定义了任意属性，那确定属性、可选属性的类型必须是它的子类型：

```typescript
interface Person {
  name: string;
  [propName: string]: string;
  // 因为 name 也是 string，符合任意属性类型，没问题
  // 如果这里 name 是 number，任意属性是 string 就报错了
}
```

### 1.5 描述函数类型

接口可以描述函数：

```typescript
interface AddFunc {
  (a: number, b: number): number;
}

const add: AddFunc = function(x, y) {
  return x + y;
};
```

### 1.6 描述索引类型（数组/对象）

```typescript
interface StringArray {
  [index: number]: string;
}

let arr: StringArray = ['a', 'b', 'c']; // 每个元素都是 string，正确
arr[0] = 1; // 错误，必须是 string
```

### 1.7 接口继承

接口可以继承其他接口，继承过来所有属性：

```typescript
interface Person {
  name: string;
  age: number;
}

interface Student extends Person {
  school: string;
  grade: number;
}

const s: Student = {
  name: '张三',
  age: 18,
  school: '清华大学',
  grade: 3
};
```

多继承：
```typescript
interface Shape {
  color: string;
}

interface PenStroke {
  penWidth: number;
}

interface Square extends Shape, PenStroke {
  sideLength: number;
}
```

### 1.8 接口合并（声明合并）

同名接口会自动合并：

```typescript
interface Box {
  height: number;
  width: number;
}

interface Box {
  color: string;
}

// 合并后：
interface Box {
  height: number;
  width: number;
  color: string;
}
```

这个特性用来给第三方库加类型，非常好用。

## 2. 类型别名 type

类型别名给任意类型起个名字：

```typescript
// 基本类型别名
type Name = string;

// 联合类型
type Age = number | string;

// 对象别名
type Point = {
  x: number;
  y: number;
};

// 元组
type Coordinate = [number, number];

// 泛型
type Container<T> = {
  value: T;
};

// 映射类型
type Readonly<T> = {
  readonly [P in keyof T]: T[P];
};
```

**type 可以给任何类型起别名，不仅仅是对象。**

## 3. 交叉类型 `&`

把多个类型合并成一个：

```typescript
interface Person {
  name: string;
}

interface Employee {
  id: number;
  department: string;
}

type Staff = Person & Employee;

const staff: Staff = {
  name: '张三',
  id: 1,
  department: '技术部'
};
// 同时有 Person 和 Employee 所有属性
```

## 4. interface vs type 区别

| 点 | interface | type |
|----|-----------|------|
| 描述对象 | ✅ | ✅ |
| 描述原始类型 | ❌ | ✅ |
| 描述联合类型 | ❌ | ✅ |
| 描述元组 | ❌ | ✅ |
| 可以继承 | `extends` | `&` 交叉 |
| 同名合并 | ✅ 自动合并 | ❌ 不能同名重复 |
| 实现（implements） | ✅ | ✅ 也可以 |
| 可以映射 | ❌ | ✅ |

## 什么时候用哪个？

**经验法则：**

1. **定义对象/类的形状，优先用 `interface`**
   - 因为 interface 可以合并，对扩展开放
   - 别人继承你的接口也方便

2. **需要定义联合类型、元组、泛型工具、映射类型，用 `type`**
   - 比如：
   ```typescript
   type Gender = 'male' | 'female'; // 联合
   type Point = [number, number]; // 元组
   type Partial<T> = { [P in keyof T]?: T[P] }; // 映射
   ```

## 5. 枚举 enum

枚举就是把所有可能的值列出来：

```typescript
enum Direction {
  Up,
  Down,
  Left,
  Right
}

// 默认从 0 开始递增，所以 Up = 0, Down = 1...

// 可以手动赋值
enum Direction {
  Up = 1,
  Down = 2,
  Left = 4,
  Right = 5
}

// 字符串枚举
enum Color {
  Red = 'red',
  Green = 'green',
  Blue = 'blue'
}

// 使用
let dir: Direction = Direction.Up;
console.log(dir); // 1
console.log(Direction[dir]); // "Up" 反向映射

// 字面量类型枚举更推荐用 type 联合
type Gender = 'male' | 'female';
// 比 enum 更简单，编译后更干净
```

### 常量枚举

编译后会被删掉，直接用值，性能更好：

```typescript
const enum Directions {
  Up,
  Down,
  Left,
  Right
}

let directions = [Directions.Up, Directions.Down];
// 编译后变成：
// let directions = [0, 1];
```

## 6. 类型体操常用操作

### keyof 拿到类型所有键

```typescript
interface Person {
  name: string;
  age: number;
}

type PersonKeys = keyof Person; // "name" | "age"
```

### typeof 拿到变量的类型

```typescript
const user = {
  name: '张三',
  age: 18
};

type UserType = typeof user;
// UserType 等价于 { name: string; age: number }
```

非常常用，从 JS 值得到 TS 类型。

### in 遍历联合类型

```typescript
type Keys = "a" | "b" | "c";
type Obj = {
  [K in Keys]: boolean;
};
// 结果：
// {
//   a: boolean;
//   b: boolean;
//   c: boolean;
// }
```

### extends 条件类型

```typescript
T extends U ? X : Y
// T 是 U 的子类型，结果是 X，否则 Y

type IsNumber<T> = T extends number ? "yes" : "no";

type A = IsNumber<123>; // "yes"
type B = IsNumber<"abc">; // "no"
```

### infer 推断类型

```typescript
// 拿到函数返回值类型
type ReturnType<T extends (...args: any) => any> =
  T extends (...args: any) => infer R ? R : any;

// 例子
function foo() {
  return 123;
}
type FooReturn = ReturnType<typeof foo>; // number
```

非常好用，infer 就是让 TS 自己推断某个位置的类型。

## 总结

- interface 描述对象形状，支持合并继承，优先用在对象
- type 是别名，什么类型都能搞，联合、元组、映射用 type
- enum 枚举，推荐用 type 联合字面量代替除非必要
- keyof typeof in extends infer 这些是类型体操基础，非常有用
