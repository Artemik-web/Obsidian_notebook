# TypeScript 高级类型

## 1. 联合类型

一个值可以是多种类型中的一种：

```typescript
let value: number | string;
value = 123;
value = 'hello';

// 只能用所有类型共有方法，要具体用得缩小类型
function getLength(x: number | string): number {
  if (typeof x === 'string') {
    // 这里 TS 知道 x 是 string
    return x.length;
  } else {
    // 这里就是 number
    return x.toString().length;
  }
}
```

## 2. 交叉类型 `&`

把多个类型合并成一个，同时拥有所有类型的属性：

```typescript
interface Person {
  name: string;
}

interface Employee {
  id: number;
  department: string;
}

type Staff = Person & Employee;

const staff: Staff = {
  name: '张三',
  id: 1,
  department: '技术部'
};
// 同时有 Person 和 Employee 所有属性
```

如果有冲突，比如两个接口同名属性类型不同，那结果就是 `never`。

## 3. 类型守卫

帮 TS 确定具体是什么类型：

### typeof

```typescript
if (typeof x === 'string') {
  // x 在这里就是 string
}
```

### instanceof

```typescript
if (x instanceof Date) {
  // x 是 Date 实例
}
```

### 自定义类型守卫

```typescript
function isFish(pet: Fish | Bird): pet is Fish {
  return (pet as Fish).swim !== undefined;
}

if (isFish(pet)) {
  pet.swim(); // TS 知道 pet 是 Fish
} else {
  pet.fly(); // 这里就是 Bird
}
```

`pet is Fish` 就是类型守卫，告诉 TS 如果返回 true，类型就是 Fish。

## 4. 可辨识联合（标签联合）

联合类型加个共同字面量标签，TS 可以很好收窄范围：

```typescript
interface Square {
  kind: 'square';
  size: number;
}

interface Rectangle {
  kind: 'rectangle';
  width: number;
  height: number;
}

interface Circle {
  kind: 'circle';
  radius: number;
}

type Shape = Square | Rectangle | Circle;

function area(s: Shape): number {
  switch (s.kind) {
    case 'square':
      return s.size * s.size; // TS 知道 s 是 Square
    case 'rectangle':
      return s.width * s.height;
    case 'circle':
      return Math.PI * s.radius ** 2;
  }
}
```

如果加 `default` 最好加个 exhaustive check：

```typescript
default:
  const _exhaustiveCheck: never = s;
  throw new Error(`unknown shape ${(s as any).kind}`);
}
```

这样如果漏了 case，编译就报错。

## 5. 映射类型

基于旧类型创建新类型，批量转换：

```typescript
// 把所有属性变成只读
type Readonly<T> = {
  readonly [P in keyof T]: T[P];
};

// 把所有属性变成可选
type Partial<T> = {
  [P in keyof T]?: T[P];
};

// 使用
interface Person {
  name: string;
  age: number;
}

type ReadonlyPerson = Readonly<Person>;
// 所有属性都只读了
```

### 加上 `-` `+` 修改修饰符

```typescript
// 去掉只读
type Mutable<T> = {
  -readonly [P in keyof T]: T[P];
};

// 去掉可选
type Required<T> = {
  [P in keyof T]-?: T[P];
};
```

### 键重映射

TS 4.1+ 支持 `as` 重新映射键：

```typescript
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K]
};

interface Person {
  name: string;
  age: number;
}
// 结果：
// {
//   getName: () => string;
//   getAge: () => number;
// }
```

非常灵活！

## 6. 条件类型

```typescript
T extends U ? X : Y
```

T 是 U 子类型返回 X，否则返回 Y。

```typescript
type IsNumber<T> = T extends number ? 'yes' : 'no';

type A = IsNumber<123>; // 'yes'
type B = IsNumber<'abc'>; // 'no'
```

### 分布式条件类型

联合类型条件，会分发给每个成员然后合并结果：

```typescript
type ToArray<T> = T extends any ? T[] : never;

type StrOrNumArr = ToArray<string | number>;
// 结果 string[] | number[]
```

## 7. infer 推断

在条件类型中 infer 可以推断某个位置的类型：

```typescript
// 推断函数返回类型
type ReturnType<T extends (...args: any) => any> =
  T extends (...args: any) => infer R ? R : any;
```

例子：
```typescript
function foo() {
  return 123;
}
type FooReturn = ReturnType<typeof foo>; // number
```

### 常用 infer 例子

**获取 Promise  resolved 类型：**
```typescript
type Awaited<T> =
  T extends Promise<infer R> ? R : never;

type PromiseNumber = Promise<number>;
type NumberType = Awaited<PromiseNumber>; // number
```

**获取数组元素类型：**
```typescript
type ArrayType<T> =
  T extends Array<infer Item> ? Item : never;

type StrArr = string[];
type StrType = ArrayType<StrArr>; // string
```

**获取第一个参数类型：**
```typescript
type FirstArg<T extends (...args: any) => any> =
  T extends (first: infer F, ...args: any) => any ? F : never;
```

infer 非常强大，类型体操很多地方要用。

## 8. 索引访问类型

```typescript
interface Person {
  name: string;
  age: number;
}

type NameType = Person['name']; // string
// 多个
type PersonTypes = Person['name' | 'age']; // string | number
```

## 9. 模板字面量类型

TS 4.1+ 支持，可以在类型层面拼接字符串：

```typescript
type World = "world";
type Greeting = `hello ${World}`;
// "hello world"

// 给所有事件加 on 前缀
type Events = "click" | "scroll";
type Handlers = {
  [E in Events as `on${Capitalize<E>}`]: () => void;
};
// 结果：
// {
//   onClick: () => void;
//   onScroll: () => void;
// }
```

`Capitalize` 内置工具类型，把第一个字母大写。
`Uncapitalize` 就是第一个字母小写。

## 10. 声明文件 `.d.ts`

给第三方 JS 库写类型声明：

```typescript
// declare 声明
declare module 'jquery' {
  function $(selector: string): any;
  export = $;
}
```

很多 npm 包已经自带类型了，没有可以装 `@types/xxx`：

```bash
npm install @types/jquery --save-dev
```

## 11. 常用模式

### 让某个属性可选

```typescript
interface Config {
  url: string;
  timeout?: number;
}
```

### 字典类型

```typescript
interface Dictionary<T> {
  [key: string]: T;
}

let obj: Dictionary<number> = {
  a: 1,
  b: 2
};
```

### 只读所有属性

```typescript
type Readonly<T> = {
  readonly [P in keyof T]: T[P];
};
```

### 深度Partial

```typescript
type DeepPartial<T> = T extends Function ? T : T extends object ? {
  [P in keyof T]?: DeepPartial<T[P]>;
} : T;
```

给对象所有层级属性加可选，非常实用。

## 总结

高级类型核心：
- 联合交叉：联合可以是多个类型之一，交叉合并多个类型
- 类型守卫收窄类型，标签联合模式很常用
- 映射类型批量修改类型，Partial Readonly 都是这么来的
- 条件类型 + infer 可以推断各种位置的类型，非常强大
- 模板字面量可以在类型层面拼字符串
- 高级类型让你写出更灵活类型安全的代码
