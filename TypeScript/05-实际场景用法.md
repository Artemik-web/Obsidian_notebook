# TypeScript 实际场景用法

这篇告诉你**什么场景用什么类型**，看完就知道什么时候该写什么了。

## 1. 基本变量

### 什么时候用 `let` / `const` / `var`
- **默认用 `const`** - 变量不会改就用 const
- 需要改才用 `let`
- 不要用 `var`，作用域坑多

### 什么时候需要显声明类型，什么时候可以让 TS 自己推断

✅ **推荐：能推断就让 TS 推断，不用写**

```typescript
// 好，TS 自动推断 age 是 number
let age = 18;
const name = 'zhangsan';

// 没必要，多此一举
let age: number = 18;
```

❌ **什么时候必须写：**

1. **变量声明了没赋值，后面才赋值**
```typescript
let age: number; // 必须写，不然 any
age = 18;
```

2. **函数参数、返回值必须写（虽然也能推断，但建议写上更清晰**
```typescript
function add(a: number, b: number): number {
  return a + b;
}
```

3. **类型不能准确推断，你要明确告诉它**
```typescript
// const users = []; // TS 推断 never[]，不对
const users: User[] = []; // 对了，告诉你是 User 数组
```

## 2. 对象

### 普通对象用 interface 还是 type？

- **普通对象推荐 interface**，可以扩展合并：

```typescript
interface User {
  name: string;
  age: number;
}

const user: User = { name: 'zhangsan', age: 18 };
```

- 需要联合/元组/工具类型用 type：

```typescript
// 联合类型，必须用 type
type Gender = 'male' | 'female';

// 坐标点元组
type Point = [number, number];
```

### 对象可选属性什么时候加 `?`

这个属性不一定有就加：

```typescript
interface User {
  name: string; // 必填，必须有
  age?: number; // 可选，可以没有
}

// 正确
const u1: User = { name: 'zhangsan' };

// 正确
const u2: User = { name: 'zhangsan', age: 18 };
```

### 对象任意属性什么时候加 `[key: string]: any`

你也不知道会有啥额外属性，允许别人加就加：

```typescript
interface Config {
  url: string;
  timeout?: number;
  [key: string]: any; // 允许加任意其他配置
}

// 现在可以加额外属性
const config: Config = {
  url: '/api',
  headers: { 'x-token': 'xxx' } // 没问题
};
```

### 只读属性什么时候加 `readonly`

初始化后不应该改就加：

```typescript
interface User {
  readonly id: number; // id 创建了就不该改
  name: string;
}

const user: User = { id: 1, name: 'zhangsan' };
user.id = 2; // ❌ TS 报错，不能改
```

## 3. 数组

### 普通数组

```typescript
// 两种写法都可以，推荐第一种
let list: number[] = [1, 2, 3];

// 泛型写法
let list: Array<number> = [1, 2, 3];
```

### 固定长度元组（每个位置类型可以不一样）

什么场景：返回多个值，固定顺序：

```typescript
// 返回 [经度, 纬度]
type Point = [number, number];
const p: Point = [116.4, 39.9];

// 例子：HTTP 响应 [状态码, 数据]
type Response = [number, any];
const res: Response = [200, { data: 'ok' }];
```

## 4. 函数

### 函数参数什么时候可选，什么时候默认值

- 参数不一定传就用可选 `arg?:`
- 不传有默认值就写默认值 `arg = xxx`

```typescript
// 可选参数
function buildName(first: string, last?: string) {
  // ...
}

buildName('zhang');
buildName('zhang', 'san');

// 默认参数
function add(a: number, b = 0) {
  return a + b;
}

add(5); // b = 0，结果 5
```

**注意：可选参数必须放最后**

### 剩余参数

不确定多少个参数用剩余参数：

```typescript
function sum(...nums: number[]) {
  return nums.reduce((a, b) => a + b, 0);
}

sum(1, 2, 3); // 6
```

### 函数重载什么时候用

同一个函数，传不同参数返回不同类型，用重载：

```typescript
// 根据传入参数不同，返回不同
function reverse(x: number): number;
function reverse(x: string): string;
function reverse(x: number | string): number | string {
  // 实现
}

reverse(123); // 返回 number
reverse('abc'); // 返回 string
```

如果就是一个参数一个返回，不用重载。

### 什么时候用 `void`，什么时候用 `never`

- `void` - 函数没有返回值，大多数情况都是这个
- `never` - 函数永远不会返回（永远抛出错误，死循环）

```typescript
// 没有返回值，用 void
function log(msg: string): void {
  console.log(msg);
}

// 永远不返回，用 never
function error(msg: string): never {
  throw new Error(msg);
}

function infiniteLoop(): never {
  while (true) {}
}
```

### 什么时候用 `any`，什么时候用 `unknown`

- `any` - 完全不知道类型，先凑合用，放弃类型检查
- `unknown` - 也不知道类型，但更安全，必须检查类型才能用

**推荐：** 能用 `unknown` 就不用 `any`，更安全。

```typescript
let value: any = 123;
value.xxx.yyy(); // any 随便点，不报错，运行可能错

let v: unknown = 123;
v.toFixed(); // ❌ 报错，先检查类型
if (typeof v === 'number') {
  v.toFixed(); // ✅ 检查过了可以用
}
```

## 5. 联合类型

什么时候用联合类型：一个变量可以是几种类型其中一个。

### 例子 1：参数可以传多种类型

```typescript
// id 可以传 number 也可以传 string
function getUser(id: number | string) {
  // ...
}

getUser(1);
getUser('1');
```

### 例子 2：状态可能是多种字面量

```typescript
type Status = 'idle' | 'loading' | 'success' | 'error';

let status: Status = 'loading';
// TS 会告诉你有哪些可选值，写错直接提示
```

这比 `string` 好太多了，类型安全，IDE 提示。

### 联合类型怎么用

必须**收窄类型**才能用具体方法：

```typescript
function getLength(x: number | string) {
  // ❌ 直接用不对，number 没有 length
  return x.length;

  // ✅ 收窄了再用
  if (typeof x === 'string') {
    return x.length; // 这里 x 确定是 string
  } else {
    return x.toString().length; // 这里就是 number
  }
}
```

常用收窄方法：
- `typeof` → 区分基本类型
- `instanceof` → 区分实例
- `in` → 检查对象有没有属性
- 自定义类型守卫 → 自己写判断

## 6. 枚举

什么时候用枚举：值是固定几个选项：

```typescript
enum Direction {
  Up,
  Down,
  Left,
  Right
}

function move(dir: Direction) {
  // ...
}

move(Direction.Up);
```

**现在更推荐用 type 联合字面量**，更简单，编译后更干净：

```typescript
type Direction = 'Up' | 'Down' | 'Left' | 'Right';
function move(dir: Direction) {
  // ...
}

move('Up');
```

只有需要兼容旧代码才用 enum，否则推荐 type 联合。

## 7. 泛型

泛型就是**类型也当参数**，让一个函数/组件支持多种类型，还保持类型安全。

### 场景 1：函数输入输出类型一样

```typescript
// 输入什么类型，输出什么类型
function identity<T>(arg: T): T {
  return arg;
}

identity(1); // 返回 number
identity('hello'); // 返回 string
```

如果不用泛型：
```typescript
// any 丢了类型信息，不行
function identity(arg: any): any {
  return arg;
}
```

### 场景 2：泛型约束，限制必须有某个属性

```typescript
// 要求 T 必须有 length 属性
interface Lengthwise {
  length: number;
}

function loggingIdentity<T extends Lengthwise>(arg: T): T {
  console.log(arg.length); // 现在可以用 length 了
  return arg;
}

loggingIdentity([1, 2, 3]); // ✅ 数组有 length
loggingIdentity('abc'); // ✅ 字符串有 length
loggingIdentity(123); // ❌ number 没有 length
```

### 场景 3：泛型工具类型，比如 Partial/Pick/Omit

给已有类型变形：

```typescript
interface User {
  name: string;
  age: number;
  email: string;
}

// 所有属性都可选，用于更新
type PartialUser = Partial<User>;
// 相当于
// {
//   name?: string;
//   age?: number;
//   email?: string;
// }

function updateUser(update: PartialUser) {
  // ...
}

// 更新只传要改的
updateUser({ age: 19 });
```

```typescript
// 只保留 name 和 email
type UserNameAndEmail = Pick<User, 'name' | 'email'>;
// 去掉 age
type UserWithoutAge = Omit<User, 'age'>;
```

### 什么时候不用泛型

就一种固定类型，不用泛型，简单就行。你写了别人用也麻烦。

## 8. 高级类型实用场景

### 交叉类型 `&` 合并多个类型

```typescript
interface Person {
  name: string;
}

interface Employee {
  id: number;
}

type Staff = Person & Employee;
// 同时有 name 和 id
```

### 可辨识联合（标签联合）

多个类型，每个有共同标签，TS 可以精确收窄：

```typescript
interface Square {
  kind: 'square';
  size: number;
}

interface Circle {
  kind: 'circle';
  radius: number;
}

type Shape = Square | Circle;

function area(s: Shape) {
  switch (s.kind) {
    case 'square':
      // 这里 s 就是 Square
      return s.size * s.size;
    case 'circle':
      // 这里 s 就是 Circle
      return Math.PI * s.radius ** 2;
  }
}
```

非常常用，写 redux reducer 经常这么用。

### infer 推断类型

获取别人的类型里某个部分：

```typescript
// 获取函数返回值类型
type ReturnType<T extends (...args: any) => any> =
  T extends (...args: any) => infer R ? R : any;

// 获取参数类型
type Parameters<T extends (...args: any) => any> =
  T extends (...args: infer P) => any ? P : never;
```

直接用内置的就好了，不用自己写。

## 9. Vue props 类型怎么写

```vue
<script setup lang="ts">
interface Props {
  title: string; // 必填
  count?: number; // 可选
  disabled?: boolean;
}

const props = defineProps<Props>();
</script>
```

默认值：

```vue
<script setup lang="ts">
interface Props {
  title: string;
  count?: number;
}

const props = withDefaults(defineProps<Props>(), {
  count: 0, // 默认 0
});
</script>
```

## 10. 发射事件类型怎么写

```vue
<script setup lang="ts">
interface Emits {
  (e: 'update', value: string): void;
  (e: 'delete', id: number): void;
}

const emit = defineEmits<Emits>();

emit('update', 'new value');
</script>
```

## 11. 响应式变量类型

大多数情况自动推断就行：

```typescript
// 自动推断 count 是 number
const count = ref(0);

const user = ref({
  name: 'zhangsan',
  age: 18
});
// 自动推断 Ref<{ name: string; age: number }>
```

需要明确类型的时候，写泛型：

```typescript
// 一开始是空，指定类型
const user = ref<User>(null);
```

reactive 也一样：

```typescript
const user = reactive<User>({
  // ...
});
```

## 12. 总结场景 checklist

| 场景 | 用法 |
|------|------|
| 普通对象 | `interface` |
| 联合/元组/类型别名 | `type` |
| 可选属性 | `?` |
| 只读属性 | `readonly` |
| 多个参数可选 | 放最后 |
| 任意额外属性 | `[key: string]: any` |
| 一个变量多种类型 | `A | B` 联合 |
| 合并多个类型 | `A & B` 交叉 |
| 固定选项枚举 | `type Status = 'a' | 'b'` 推荐，`enum` 不推荐 |
| 类型不变用 | `const`，变了用 `let` |
| 能推断不写类型 | 对，不写，干净 |
| 空数组一开始 | `const arr: Type[] = []` |
| 函数没返回 | `void` |
| 函数永不返回 | `never` |
| 不知道类型 | `unknown` 比 `any` 好 |
| 泛型：类型复用保持安全 | `<T>` 传类型参数 |
| 泛型约束 | `T extends XXX` 限制必须有什么属性 |
- 工具类型：Partial / Pick / Omit / ReturnType / Parameters 这些内置直接用

按这个来，写出来的类型就清晰好用，不会瞎搞。
