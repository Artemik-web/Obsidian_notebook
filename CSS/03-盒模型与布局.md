# CSS 盒模型与布局

## 1. 盒模型基础

每个 HTML 元素都是一个盒子。盒子由四部分组成：
- **content** - 内容区域（放文字、图片）
- **padding** - 内边距（内容和边框之间）
- **border** - 边框（padding 外面的边框）
- **margin** - 外边距（盒子外面的空间）

图解：
```
| ← margin 外 → ← 盒子宽度 → |
|         |← padding →|     |
| border  +-----------------+ |
|         |  content       | |
|         |  内容区域       | |
|         +-----------------+ |
```

## 2. box-sizing

`box-sizing` 决定了 `width` 计算方式：

### 2.1 `content-box`（默认）

```css
.box {
  width: 100px;
  padding: 10px;
  border: 1px solid #000;
  /* 实际总宽度 = 100 + 10*2 + 1*2 = 122px */
  box-sizing: content-box;
}
```

width 指的是 **内容宽度**，padding 和 border 会额外增加宽度。

### 2.2 `border-box`（推荐！）

```css
.box {
  width: 100px;
  padding: 10px;
  border: 1px solid #000;
  /* 实际总宽度 = 100px
     content 宽度 = 100 - 10*2 - 1*2 = 78px */
  box-sizing: border-box;
}
```

width 指的是 **总宽度**（content + padding + border），所以不会被 padding 和 border 撑大。

**全局重置推荐：**
```css
* {
  box-sizing: border-box;
}
```

这样写布局更容易计算尺寸。

## 3. margin 合并（折叠）

### 3.1 什么是 margin 合并？

**垂直方向**上相邻的两个块级元素，上下 margin 会合并成一个，取较大值。

例子：
```css
h1 {
  margin-bottom: 20px;
}
p {
  margin-top: 10px;
}
/* 实际间距是 max(20, 10) = 20px，不是 30px */
```

### 3.2 父子 margin 塌陷

如果父元素没有 border/padding，父子的 margin 也会合并：

```css
<div class="parent">
  <p>子元素</p>
</div>

<style>
.parent {
  background: #eee;
  /* 没有 padding/border，所以子的 margin-top 会塌陷到父上面 */
  margin-top: 0;
}
p {
  margin-top: 20px;
}
</style>
```

### 3.3 如何防止 margin 合并？

方法：
1. 父元素加 `overflow: hidden`（触发 BFC）
2. 父元素加 `border-top` / `padding-top`
3. 使用 flex 布局不会合并
4. 用 padding 代替 margin 垂直间距（看场景）

```css
/* 方法 1：BFC 防止塌陷 */
.parent {
  overflow: hidden;
}

/* 方法 2：加一点点 padding */
.parent {
  padding-top: 1px;
}
```

### 3.4 margin 合并只会发生在垂直方向！

水平方向不会合并，放心用。

## 4. margin 居中

块级元素水平居中，宽度固定：

```css
.box {
  width: 960px;
  margin-left: auto;
  margin-right: auto;
  /* 简写 */
  margin: 0 auto;
}
```

- `margin: 0 auto` 只对**宽度确定**的块级生效
- 行内元素/行内块不行？设置 `display: block` 然后 margin auto
- flex 水平居中用 `justify-content: center`

## 5. display 常见值

| 值 | 说明 |
|----|------|
| `block` | 块级，独占一行，可设宽高 |
| `inline` | 行内，不换行，宽高由内容决定，不能设宽高 |
| `inline-block` | 不换行，可以设宽高 |
| `none` | 隐藏，不占位置，点击也无效 |
| `flex` | flex 弹性布局 |
| `grid` | grid 网格布局 |
| `table` | 表格布局 |

**`display: none` vs `visibility: hidden` vs `opacity: 0`:**

| 方式 | 是否占位 | 是否可点击 |
|------|----------|------------|
| `display: none` | 不占位 | 不能 |
| `visibility: hidden` | 占位 | 不能 |
| `opacity: 0` | 占位 | 可以 |

## 6. 浮动布局 float

浮动原本用于实现文字环绕图片，后来被用来布局。

### 6.1 浮动特性

```css
.box {
  float: left; /* 向左浮 */
  /* float: right; 向右浮 */
  /* float: none; 不浮 */
}
```

浮动会：
- 脱离正常文档流（不占原来位置）
- 浮到父容器的左边/右边
- 浮动元素会靠左/靠右排列，放不下就换行

### 6.2 浮动问题：高度塌陷

父元素不写高度时，子元素都浮动了，父元素高度会变成 0。

### 6.3 清除浮动方法（推荐！）

给父元素加 `clearfix` 类：

```css
.clearfix::after {
  content: "";
  display: block;
  clear: both;
  /* 兼容旧浏览器可选加上 */
  visibility: hidden;
  height: 0;
}
```

HTML：
```html
<div class="parent clearfix">
  <div class="left" style="float: left;">左</div>
  <div class="right" style="float: right;">右</div>
</div>
```

### 6.4 其他清除浮动方式

```css
/* 方法：父元素 overflow: hidden */
.parent {
  overflow: hidden;
}

/* 方法：额外标签 */
<div class="parent">
  <div style="float: left;">...</div>
  <div style="clear: both;"></div>
</div>
```

不推荐额外标签法，增加无意义标签。

### 6.5 浮动双栏布局

```css
.left {
  width: 200px;
  float: left;
}
.right {
  margin-left: 220px; /* 左边宽度 + 间距 */
}
```

### 6.6 浮动三栏布局

```css
.left { float: left; width: 200px; }
.right { float: right; width: 200px; }
.center { margin: 0 220px; }
```

**现在浮动基本不用来布局了，用 Flex/Grid 更方便。**

## 7. Flex 布局（弹性盒）强烈推荐！

### 7.1 基本概念

- `display: flex` 的元素叫 **容器**（flex container）
- 容器里面的子元素叫 **项目**（flex item）
- 主轴（main axis）：默认水平方向
- 交叉轴（cross axis）：默认垂直方向

### 7.2 容器常用属性

```css
.container {
  display: flex;
  /* 主轴方向 */
  flex-direction: row;         /* 默认，从左到右 */
  /* flex-direction: column;    从上到下 */
  /* flex-direction: row-reverse; 从右到左 */

  /* 换行 */
  flex-wrap: nowrap; /* 默认，不换行，挤在一起 */
  /* flex-wrap: wrap;  放不下就换行 */

  /* 主轴对齐方式 */
  justify-content: flex-start;  /* 起点对齐（默认） */
  /* justify-content: flex-end;    终点对齐 */
  /* justify-content: center;      居中 */
  /* justify-content: space-between; 两端对齐，项目中间间距相等 */
  /* justify-content: space-around;  项目周围间距相等 */
  /* justify-content: space-evenly;  所有间距相等（包括两端） */

  /* 交叉轴对齐方式 */
  align-items: stretch;   /* 默认，拉伸占满高度 */
  /* align-items: flex-start; 起点对齐 */
  /* align-items: flex-end;   终点对齐 */
  /* align-items: center;     居中 */
  /* align-items: baseline;   基线对齐（文字底部对齐） */

  /* 多行时，行对齐 */
  align-content: stretch; /* 默认拉伸 */
}
```

### 7.3 项目常用属性

```css
.item {
  /* 项目排序，数值越小越靠前，默认 0 */
  order: 0;

  /* 放大比例，空间多余时分配 */
  flex-grow: 0; /* 默认 0，不放大 */
  /* flex-grow: 1; 所有项目分多余空间 */

  /* 缩小比例，空间不够时缩小 */
  flex-shrink: 1; /* 默认 1，空间不够会缩小 */
  /* flex-shrink: 0; 不缩小 */

  /* 项目基础大小 */
  flex-basis: auto; /* 默认 auto，就是原来宽度 */
  /* flex-basis: 200px; 主轴上基础大小 */

  /* flex 缩写：flex: grow shrink basis */
  flex: 1; /* flex: 1 1 0% → 平分剩余空间，常用 */
  flex: auto; /* 1 1 auto */
  flex: none; /* 0 0 auto → 不放大不缩小 */

  /* 单个项目对齐，覆盖容器 align-items */
  align-self: auto;
  /* align-self: center; 自己居中 */
}
```

### 7.4 Flex 常用场景

**1. 水平垂直居中**
```css
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

**2. 两端对齐**
```css
.container {
  display: flex;
  justify-content: space-between;
}
```

**3. 固定左侧 + 自适应右侧**
```css
.container {
  display: flex;
  gap: 20px;
}
.left {
  width: 200px;
  flex-shrink: 0; /* 不要缩小 */
}
.right {
  flex: 1; /* 占剩余所有 */
}
```

**4. 平均分布 3 列**
```css
.container {
  display: flex;
  gap: 20px;
}
.item {
  flex: 1; /* 每列平分宽度 */
}
```

**5. 导航栏**
```css
.nav {
  display: flex;
  align-items: center;
  height: 60px;
  gap: 20px;
}
```

**6. 自适应九宫格**
```css
.grid {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}
.item {
  /* 每行三个，减去间隙 */
  width: calc((100% - 20px) / 3);
}
```

**7. 圣杯布局**
```css
.container {
  display: flex;
}
.left { width: 200px; flex-shrink: 0; }
.center { flex: 1; }
.right { width: 200px; flex-shrink: 0; }
```

比浮动方便太多！

### 7.5 gap 属性（间距）

```css
.container {
  display: flex;
  gap: 10px;        /* 水平垂直都是 10px */
  /* row-gap: 10px;  行间距 */
  /* column-gap: 20px; 列间距 */
}
```

直接用 gap 设置项目间距，不用 margin 了，舒服！

## 8. Grid 布局（网格）

适合二维布局（多行多列）。

### 8.1 基本用法

```css
.container {
  display: grid;
  /* 定义三列，每列宽度 */
  grid-template-columns: 200px 1fr 1fr;
  /* 定义行高度 */
  grid-template-rows: 100px auto;
  /* 间距 */
  gap: 10px;
}
```

`fr` 是分数单位，代表剩余空间的比例。

### 8.2 常用重复写法

```css
/* 3 列，每列 1fr 平分 */
grid-template-columns: repeat(3, 1fr);

/* 每列最小 100px，自动填满 */
grid-template-columns: repeat(auto-fill, minmax(100px, 1fr));

/* 自适应，最少 200px，自动换行 */
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
```

### 8.3 九宫格

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(3, 1fr);
  gap: 10px;
  aspect-ratio: 1/1;
}
```

### 8.4 项目定位

```css
.item {
  /* 从哪开始，到哪结束 */
  grid-column-start: 1;
  grid-column-end: 3; /* 跨 2 列 */
  /* 缩写 */
  grid-column: 1 / 3;
  grid-row: 1 / 2;
}
```

## 9. 定位 position

### 9.1 position 取值

| 值 | 说明 | 定位基准 |
|----|------|----------|
| `static` | 默认，正常文档流 | 无定位 |
| `relative` | 相对定位 | 相对于自己原来位置 |
| `absolute` | 绝对定位 | 相对于最近的 `position != static` 的祖先 |
| `fixed` | 固定定位 | 相对于视口（浏览器窗口） |
| `sticky` | 粘性定位 | 相对于视口和最近祖先 |

### 9.2 `relative`

```css
.box {
  position: relative;
  top: 10px;
  left: 10px;
}
```

- 原来位置保留，不会空出来
- 一般用来做 absolute 的父容器

### 9.3 `absolute`

```css
.box {
  position: absolute;
  top: 0;
  left: 0;
}
```

- 脱离文档流，不占位置
- 相对于最近非 static 祖先
- 如果祖先都没有定位，相对于 html

**子绝父相：** 子元素 absolute，父元素 relative（常用）

### 9.4 `fixed`

```css
.fixed-header {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  z-index: 999;
}
```

固定在视口某个位置，滚动页面不会动。常用作固定头部、返回顶部按钮。

### 9.5 `sticky`

```css
/* 吸顶效果 */
.header {
  position: sticky;
  top: 0; /* 滚动到顶部时吸住 */
}
```

用户滚动到它出视口顶部时，就固定住，非常好用！

### 9.6 居中：绝对定位水平垂直居中

```css
/* 方法一：需要知道宽高 */
.box {
  position: absolute;
  top: 50%;
  left: 50%;
  width: 200px;
  height: 100px;
  margin-top: -50px;
  margin-left: -100px;
}

/* 方法二：不用知道宽高（推荐） */
.box {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

## 10. 布局对比总结

| 布局方式 | 适用场景 |
|----------|----------|
| 标准流 | 普通文档流，从上到下 |
| 浮动 | 文字环绕，不推荐整体布局 |
| Flex | 一维布局（行/列），导航、卡片排列、圣杯 → 非常推荐！ |
| Grid | 二维布局（多行多列），网格系统 → 非常推荐！ |
| 绝对定位 | 弹窗、下拉菜单、小部件悬浮 |
| 固定定位 | 固定头部、侧边栏 |
| 粘性定位 | 吸顶、吸边 |

**现代开发推荐：Flex + Grid 一把梭，浮动只用来浮动就好了。**
