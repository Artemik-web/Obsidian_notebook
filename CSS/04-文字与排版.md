# CSS 文字与排版

## 1. 字体相关属性

### 1.1 font-size 字体大小

```css
p {
  /* 常用单位 */
  font-size: 16px;   /* 像素 */
  font-size: 1rem;  /* 相对于根元素 html 的字体大小，默认 1rem = 16px */
  font-size: 1em;   /* 相对于父元素字体大小 */
  font-size: 120%; /* 百分比，相对于父元素 */
  font-size: small; /* 关键字 */
}
```

**最佳实践：**
- 正文一般 `14px` ~ `16px`
- 标题根据层级增大
- 移动端建议不要小于 `12px`

### 1.2 font-family 字体族

```css
body {
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Microsoft YaHei", sans-serif;
}
```

**字体分类：**
- `serif` - 衬线字体（有边角装饰，比如宋体、Times New Roman）
- `sans-serif` - 无衬线字体（干净清爽，现代网页常用）
- `monospace` - 等宽字体（每个字母宽度相同，用于代码）
- `cursive` - 手写体
- `fantasy` - 装饰字体

**写法：** 写多个字体，从左往右依次 fallback：
```css
/* 优先第一个字体，如果用户没有就用第二个，依此类推，最后写字体分类兜底 */
font-family: "Microsoft YaHei", Arial, sans-serif;
```

**注意：** 字体名有空格要加引号：`"Segoe UI"`

### 1.3 font-weight 字重（粗细）

```css
/* 关键字 */
font-weight: normal; /* 400 */
font-weight: bold;   /* 700 */
font-weight: lighter;
font-weight: bolder;

/* 数值（更精确） */
font-weight: 100;
font-weight: 300;
font-weight: 400; /* 正常 */
font-weight: 500;
font-weight: 700; /* 粗体 */
font-weight: 900;
```

- 400 = normal
- 700 = bold

### 1.4 font-style 字体样式

```css
font-style: normal;  /* 正常，默认 */
font-style: italic;  /* 斜体 */
font-style: oblique; /* 倾斜，很少用 */
```

一般用 `<em>` 表示强调斜体，CSS 这里用来恢复正常：
```css
em {
  font-style: normal; /* 如果不想要斜体 */
}
```

### 1.5 font 缩写

顺序：`style weight size/line-height family`

```css
/* 完整写法 */
font: italic bold 16px/1.5 "Microsoft YaHei", sans-serif;

/* 常用简写 */
font: 16px/1.5 sans-serif;
```

**要求：** 必须写 `size` 和 `family`，其他可以省略。

## 2. 文本样式

### 2.1 color 文字颜色

```css
color: red;            /* 关键字 */
color: #ff0000;       /* 十六进制 */
color: rgb(255, 0, 0); /* RGB */
color: rgba(255, 0, 0, 0.5); /* 带透明度 */
```

### 2.2 text-align 水平对齐

```css
text-align: left;     /* 左对齐（默认） */
text-align: center;   /* 居中 */
text-align: right;    /* 右对齐 */
text-align: justify;  /* 两端对齐 */
```

对块级元素生效，让内部文本、行内元素对齐。

### 2.3 line-height 行高

行高 = 文字上方 + 文字 + 文字下方的总高度。

```css
line-height: 1.5;     /* 倍数：相对于当前字体大小 */
line-height: 24px;    /* 固定像素 */
line-height: 150%;    /* 百分比 */
```

**经验：**
- 正文行高：`1.5` ~ `1.8` 比较舒服
- 标题行高：`1.2` ~ `1.3`
- 单行文字垂直居中：`line-height = height`

```css
/* 单行垂直居中 */
.nav-item {
  height: 40px;
  line-height: 40px;
}
```

### 2.4 text-decoration 文本装饰线

```css
a {
  text-decoration: none; /* 去掉下划线，常用 */
}
text-decoration: underline;    /* 下划线 */
text-decoration: overline;     /* 上划线 */
text-decoration: line-through; /* 删除线 */
```

### 2.5 text-indent 首行缩进

```css
p {
  text-indent: 2em; /* 首行缩进两个汉字 */
}
```

`2em` 正好缩进两个中文字，非常方便。

### 2.6 text-transform 大小写转换

```css
text-transform: none;
text-transform: uppercase; /* 全大写 */
text-transform: lowercase; /* 全小写 */
text-transform: capitalize; /* 首字母大写 */
```

### 2.7 letter-spacing 字间距 / word-spacing 词间距

```css
/* 字与字之间的间距 */
letter-spacing: 2px;

/* 词与词之间的间距（空格的宽度） */
word-spacing: 4px;
```

### 2.8 white-space 空白处理

```css
white-space: normal;  /* 合并多个空格换行为一个，自动换行（默认） */
white-space: nowrap;  /* 不换行，一直下去，除非 <br> */
white-space: pre;     /* 保留空白，不自动换行（类似 <pre>）*/
white-space: pre-wrap;/* 保留空白，自动换行 */
white-space: pre-line;/* 合并空格，保留换行符，自动换行 */
```

常用：`white-space: nowrap` 让文字不换行。

### 2.9 overflow 溢出处理

```css
/* 单行溢出显示省略号 */
.text-ellipsis {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}

/* 多行溢出显示省略号（WebKit 内核浏览器，可以用） */
.text-ellipsis-2 {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 2; /* 两行 */
  overflow: hidden;
}
```

## 3. 字体图标

引入字体图标：
```html
<link rel="stylesheet" href="https://cdn.bootcdn.net/ajax/libs/font-awesome/6.4.0/css/all.min.css">
```

使用：
```html
<i class="fa fa-search"></i>
```

优点：
- 矢量化，缩放不失真
- 体积小
- 方便改颜色大小

## 4. 自定义字体（web fonts）

```css
@font-face {
  font-family: "MyFont";
  src: url("myfont.woff2") format("woff2"),
       url("myfont.woff") format("woff");
  font-weight: normal;
  font-style: normal;
}

body {
  font-family: "MyFont", sans-serif;
}
```

现在越来越多网站用自定义字体了。

## 5. CSS 变量（自定义属性）

可以定义主题颜色，方便切换主题：

```css
:root {
  --primary-color: #007bff;
  --text-color: #333;
  --bg-color: #fff;
}

body {
  color: var(--text-color);
  background: var(--bg-color);
}

.button {
  background: var(--primary-color);
}

/* 暗黑模式切换 */
body.dark {
  --text-color: #eee;
  --bg-color: #1a1a1a;
}
```

非常方便！

## 6. 排版最佳实践

### 6.1 文字颜色对比度

- 正文文字对比度至少 4.5:1（WCAG 标准）
- 大文字至少 3:1
- 不要用太浅灰色文字放浅色背景

### 6.2 行高建议

| 类型 | 行高 |
|------|------|
| 大标题 | 1.2 ~ 1.3 |
| 正文 | 1.5 ~ 1.8 |
| 代码 | 1.2 ~ 1.4 |

### 6.3 容器宽度

一行文字太长读着累，限制容器宽度：

```css
article {
  max-width: 700px;
  margin: 0 auto;
}
```

一般一行 45 ~ 75 个汉字体验最好。

### 6.4 层级清晰

```css
h1 { font-size: 32px; font-weight: bold; }
h2 { font-size: 24px; font-weight: bold; }
h3 { font-size: 20px; font-weight: 600; }
h4 { font-size: 16px; font-weight: 600; }
p { font-size: 16px; line-height: 1.8; color: #333; }
small { font-size: 14px; color: #666; }
```

字号大小从上到下递减，层级清晰。

### 6.5 去掉 a 标签默认下划线

```css
a {
  text-decoration: none;
  color: var(--primary-color);
}
a:hover {
  text-decoration: underline;
}
```

 hover 显示下划线比较美观。

### 6.6 换行和不换行

```css
/* 不换行 */
.nowrap {
  white-space: nowrap;
}

/* 允许长单词换行 */
.break-word {
  word-wrap: break-word;
  word-break: break-all;
}
```

## 7. 常用 CSS 重置

不同浏览器默认样式不一样，重置一下：

```css
/* 重置和基础样式 */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

html, body {
  height: 100%;
}

body {
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Microsoft YaHei", sans-serif;
  font-size: 16px;
  line-height: 1.6;
  color: #333;
  background-color: #fff;
  -webkit-font-smoothing: antialiased; /* 抗锯齿，更清晰 */
  -moz-osx-font-smoothing: grayscale;
}

ul, ol {
  list-style: none;
}

a {
  color: #007bff;
  text-decoration: none;
}
a:hover {
  text-decoration: underline;
}

img {
  max-width: 100%;
  height: auto;
  display: block; /* 去掉图片底部默认缝隙 */
}

button, input, textarea {
  font: inherit; /* 继承字体，默认按钮输入不继承，加上这个统一 */
  outline: none;
}

button {
  cursor: pointer;
}

h1, h2, h3, h4, h5, h6 {
  font-weight: 600;
  line-height: 1.2;
}

/* 清除浮动 */
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}
```

有了这个基础，写出来的页面在各个浏览器表现一致。

## 8. 垂直居中总结

### 单行文字：
```css
.center {
  height: 40px;
  line-height: 40px;
}
```

### Flex 水平垂直居中（推荐）：
```css
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
```

### 绝对定位居中（知道宽高不知道都可以）：
```css
.parent {
  position: relative;
}
.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

## 9. 练习

创建一个文章页面排版：
- 标题 h1: 28px 粗体
- 作者信息: 14px 灰色
- 正文 p: 16px 行高 1.8 颜色 #333
- 段落首行缩进 2em
- 段落之间 margin-bottom 16px
- 图片 宽度 100%
- 代码块 背景 #f5f5f5 padding 16px 圆角 4px 字体 monospace
