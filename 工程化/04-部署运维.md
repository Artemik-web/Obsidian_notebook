# 部署运维

## Docker 容器化

### 什么是 Docker

- 把应用和依赖打包成一个镜像，任何机器跑起来都一样
- 解决"我本机跑没问题啊，为什么线上错了"问题
- 容器和宿主机隔离，环境干净

### Dockerfile 例子 - Vue/React 项目

```dockerfile
# 构建阶段
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 生产阶段，用 nginx 放静态文件
FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### 常用命令

```bash
# 构建镜像
docker build -t my-app .

# 运行容器
docker run -p 80:80 -d my-app

# 查看运行中容器
docker ps

# 看日志
docker logs <container-id>

# 停止容器
docker stop <container-id>
```

### docker-compose

多个容器一起管理，比如前端 + 后端 + 数据库一起起：

```yaml
version: '3.8'
services:
  frontend:
    build: .
    ports:
      - "80:80"
  backend:
    build: ../backend
    ports:
      - "3000:3000"
  database:
    image: postgres:15
    environment:
      POSTGRES_PASSWORD: 123456
    volumes:
      - postgres-data:/var/lib/postgresql/data
volumes:
  postgres-data:
```

## Nginx 配置

### 静态网站配置

```nginx
server {
    listen 80;
    server_name example.com www.example.com;

    # 静态文件根目录
    root /usr/share/nginx/html;
    index index.html;

    # Vue/React 路由 history 模式，所有请求 fallback 到 index.html
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control public;
    }
}
```

### 反向代理解决跨域

```nginx
server {
    listen 80;
    server_name example.com;

    root /usr/share/nginx/html;

    # 接口请求代理到后端
    location /api/ {
        proxy_pass http://backend:3000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### HTTPS 配置 (Let's Encrypt)

```nginx
server {
    listen 443 ssl;
    server_name example.com;

    ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

    # ... 其他配置 ...
}

# HTTP 跳 HTTPS
server {
    listen 80;
    server_name example.com;
    return 301 https://$server_name$request_uri;
}
```

## CDN 配置

### 什么是 CDN

- 静态资源放到离用户近的节点，用户打开更快
- 源站在国内，海外用户也快
- 分摊源站压力，大流量不怕

### 配置

- 把 `https://example.com/js/app.js` 改成 `https://cdn.example.com/js/app.js`
- DNS 解析到 CDN 服务商
- 静态资源设置较长缓存时间，变了换文件名 hash

## 静态网站托管

免费/便宜托管选择：

- **GitHub Pages** - 免费，适合个人项目博客
- **Vercel** - 免费，前端项目零配置部署
- **Netlify** - 类似 Vercel
- **阿里云 OSS / 腾讯云 COS** - 对象存储，托管静态网站，按流量收费
- **自己服务器** - Nginx 直接放

## 前端部署流程

典型的现代前端项目：

1. 开发者 push 代码到 GitHub
2. GitHub Actions 自动触发，安装依赖 → 构建 → 测试
3. 构建完得到 `dist/` 目录
4. 上传到 CDN / OSS / 服务器
5. 如果用 Docker，构建镜像推到镜像仓库，服务器拉新镜像重启

## 常见问题

### 刷新 404
- **原因**：SPA 路由 history 模式，文件不存在
- **解决**：Nginx 配置 `try_files $uri $uri/ /index.html;`，所有路径回 index.html

### 改了代码不更新
- **原因**：浏览器缓存了旧文件
- **解决**：打包文件名加 contenthash，变了文件名就变，不会缓存旧的
