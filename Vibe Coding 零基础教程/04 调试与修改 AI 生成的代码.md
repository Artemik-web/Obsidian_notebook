# 04 调试与修改 AI 生成的代码

> 代码跑不起来？不用担心，AI 帮你找 bug。

---

## Vibe Coding 的调试哲学

```
传统调试：
  自己看代码 → 猜哪里错了 → Google 搜 → 试 → 不行再来

Vibe Coding 调试：
  复制报错信息 → 发给 AI → AI 告诉你怎么改 → 改完跑起来
```

---

## 场景一：代码没反应 / 白屏

### 怎么办

1. 打开浏览器开发者工具（F12）
2. 看 Console（控制台）有没有红字
3. 把红字复制给 AI

### 发给 AI

```
我的网页打开是白屏，控制台报这个错：
（粘贴报错信息）

这是我的代码：
（粘贴代码）

帮我看是什么问题。
```

---

## 场景二：样子不对

### 怎么办

截图发给 AI（或用文字描述），说清楚：

```
我想要的：按钮是圆角蓝色，居中
实际看到：按钮是方形灰色，靠左

帮我改。
```

如果 AI 支持图片，直接截图发效果更好。

---

## 场景三：功能不工作

### 举例：点击按钮没反应

```
发给 AI：

（附代码）
我点击「提交」按钮后应该弹出一个提示，
但现在点击了没反应。帮我检查一下。
```

### AI 通常会检查

- 按钮的 id/class 有没有写对
- JavaScript 函数有没有绑定到按钮
- 拼写有没有错误
- 事件监听有没有写

---

## 场景四：不知道问题在哪

### 万能句式

```
这是我的完整代码（附代码），
出现了 [描述问题]，
帮我 debug，告诉我哪里错了、怎么改。
```

---

## 常用调试指令

| 你想要的 | 对 AI 说 |
|----------|----------|
| 检查语法错误 | 「帮我检查这段代码有没有语法错误」 |
| 优化性能 | 「这个页面加载很慢，帮我看看哪里可以优化」 |
| 让代码更整洁 | 「帮我把这段代码重构一下，让它更易读」 |
| 兼容不同浏览器 | 「这个在 Chrome 正常，在 Safari 有问题，帮我兼容」 |
| 改一个变量名 | 「帮我把所有的 `data` 改成 `userData`」 |
| 拆分大文件 | 「这个文件太长了，帮我拆成多个文件」 |

---

## 浏览器调试速查

### F12 开发者工具关键面板

| 面板 | 用途 |
|------|------|
| Console | 看报错、打印调试信息 |
| Elements | 看 HTML 结构和 CSS 样式 |
| Network | 看文件加载是否成功 |
| Sources | 打断点调试 JavaScript |

---

## 常用 console.log 调试

在你的代码里加：

```javascript
console.log('走到这里了')          // 看代码有没有执行到
console.log('用户数据:', userData) // 看变量值对不对
console.log('按钮被点击了')        // 看事件有没有触发
```

怎么看？打开 F12 → Console 面板。

---

## 调试工作流总结

```
发现问题
  ↓
F12 看 Console（有报错就复制报错）
  ↓
截图或者描述「我想要的 vs 实际看到的」
  ↓
把代码+报错+问题描述一起发给 AI
  ↓
AI 给你修改后的代码
  ↓
复制粘贴 → 刷新页面 → 检查
  ↓
解决了？→ ✅
没解决？→ 告诉 AI「还是不行，[新现象]」→ 回到上一步
```

---

## 一句话记住

> **把报错信息复制给 AI，90% 的问题 AI 都能修。不要自己瞎猜。**
