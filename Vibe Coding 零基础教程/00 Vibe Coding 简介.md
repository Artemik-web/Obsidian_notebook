# 00 Vibe Coding 简介

## 什么是 Vibe Coding？

Vibe Coding 是一种**用自然语言描述需求、让 AI 帮你写代码**的编程方式。

你不必精确记住每一个语法，只需要清楚地告诉 AI **「我要什么」**，AI 就会生成可运行的代码。

> **一句话**：你说人话，AI 写代码。

---

## 为什么叫 Vibe Coding？

- **Vibe** = 氛围、感觉、直觉
- 你不需要死记语法、不用纠结技术细节
- 你描述需求、给方向，代码由 AI 完成
- 就像和朋友聊天一样编程

---

## Vibe Coding vs 传统编程

| 对比 | 传统编程 | Vibe Coding |
|------|----------|-------------|
| 入门门槛 | 需学语法、框架、工具链 | 会说需求就行 |
| 编码速度 | 慢，逐行手写 | 快，描述即可生成 |
| 调试方式 | 自己找 bug | AI 帮你找 bug |
| 学习方式 | 从语法开始学 | 从需求开始做 |
| 适合谁 | 专业开发者 | 任何人 |

---

## Vibe Coding 的核心思想

```
传统编程：
  学语法 → 学框架 → 写代码 → 调试 → 上线

Vibe Coding：
  说需求 → AI 生成代码 → 检查运行 → 微调 → 上线
```

---

## 你需要会什么？

### 必须会（门槛极低）

- [ ] 能用中文/英文清晰描述需求
- [ ] 知道什么是网页、什么是 App
- [ ] 会复制粘贴代码

### 慢慢学（边做边学）

- [ ] 看懂基本的文件结构（HTML/CSS/JS 是什么）
- [ ] 会在浏览器里打开网页
- [ ] 会用终端/命令行（也是让 AI 教你）

### 不需要会

- [ ] 不需要背语法
- [ ] 不需要学框架
- [ ] 不需要记住 API 文档

## Vibe Coding 能做什么？

| 场景 | 例子 |
|------|------|
| 网页开发 | 做一个个人博客、公司官网、商品展示页 |
| 小程序 | 做一个工具类小程序 |
| 自动化脚本 | 批量处理文件、自动发邮件 |
| 数据分析 | 图表可视化、Excel 自动化 |
| 小游戏 | 做一个简单的浏览器小游戏 |
| API 接口 | 做一个后端接口服务器 |

## 学习路线

```
[第 1 步] 理解 Vibe Coding 是什么            ← 你在这里
[第 2 步] 搭建开发环境（安装工具）
[第 3 步] 用 AI 完成第一个网页
[第 4 步] 学会"提示词"——怎么跟 AI 说清楚
[第 5 步] 调试和修改 AI 生成的代码
[第 6 步] 做一个完整的项目
[第 7 步] 部署上线，让全世界看到
```

---

## 三个最重要的原则

### 1. 需求要清晰

```
❌ 差的描述：「做一个网页」
✅ 好的描述：「做一个个人主页，顶部是我的名字和照片，
          中间是我的项目经历（卡片式排列），
          底部是联系方式。颜色用白色背景+蓝色主题。」
```

### 2. 小步快跑

```
不要一次说完所有需求。
先做一个简单的版本，跑起来，再逐步加功能。

第 1 步：做一个只有标题的网页
第 2 步：加一段自我介绍
第 3 步：加一个图片
第 4 步：加样式美化
...
```

### 3. 不懂就问 AI

```
「这段代码是什么意思？」
「为什么报这个错？」
「怎么把这个按钮改大一点？」
「给我解释一下这个文件是干嘛的」
```
