# 02 第一个 Vibe Coding 项目

> 目标：用 AI 做一个完整的网页，看到 Vibe Coding 的全流程。

---

## 项目目标

做一个**个人名片页面**，包含：
- 你的名字和头像
- 一句自我介绍
- 三个技能标签
- 社交媒体链接

---

## 第一步：在 AI 里描述你的需求

打开 Claude / ChatGPT，复制下面这段话（替换你的信息）：

```
帮我做一个个人名片网页，要求：
1. 白色背景，卡片居中显示
2. 顶部是圆形头像（先用占位图）
3. 中间是我的名字「你的名字」和一句话介绍「一个在学习 Vibe Coding 的人」
4. 下面三个技能标签：HTML、CSS、JavaScript（蓝色圆角标签）
5. 底部是 GitHub 和邮箱链接
6. 整体干净简洁，用 HTML + CSS 写在一个文件里
```

AI 会生成一段 HTML 代码。

---

## 第二步：把代码放到文件里

1. 在 VS Code 的项目文件夹里新建 `profile.html`
2. 把 AI 生成的代码**全部复制**进去
3. 保存（Ctrl + S）

---

## 第三步：预览效果

1. 在 VS Code 里右键 `profile.html` → **Open with Live Server**
2. 浏览器打开，看到你的名片页面

---

## 第四步：不满意就改

### 怎么改？

**跟 AI 说，让 AI 改。**

```
示例对话：

你：「帮我把背景改成浅蓝色」
AI：（生成修改后的代码）

你：「头像再大一点，文字再大一点」
AI：（生成修改后的代码）

你：「技能标签换个配色，用绿色渐变」
AI：（生成修改后的代码）
```

### 每一轮修改的流程

```
说出不满意的点 → AI 给新代码 → 复制粘贴 → 刷新页面看效果 → 继续改
```

---

## 第五步：加上响应式（手机也能看）

告诉 AI：

```
给这个页面加上响应式设计，在手机上也能正常显示。
手机端卡片宽度占满屏幕，头像变小一点。
```

---

## 第六步：部署到互联网（可选）

### 最简单的方法：GitHub Pages

告诉 AI：

```
帮我用 GitHub Pages 部署这个网页，一步一步教我。
```

AI 会告诉你每一步怎么做。

### 更简单：Netlify Drop

1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)
2. 把 `profile.html` 文件拖进去
3. 得到一个网址，任何人都能访问

---

## 你刚完成了什么

```
你说了一句话 → AI 写了完整代码 → 复制粘贴 → 网页上线
```

这就是 Vibe Coding 的标准流程。

---

## 关键心得

| 心得 | 说明 |
|------|------|
| **一次只改一件事** | 不要一次说一堆，AI 容易漏 |
| **先跑起来再优化** | 丑没关系，能看就行，后面慢慢改 |
| **报错了就问 AI** | 把报错信息复制给 AI，它知道怎么修 |
| **多和 AI 对话** | 就像和同事讨论一样，不要怕问 |
