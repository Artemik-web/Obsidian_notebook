# 05 完整项目实战

> 目标：从头到尾用 Vibe Coding 做一个能上线的完整项目。

---

## 项目：个人作品集网站

**功能清单**：
- 首页：个人介绍 + 头像
- 项目展示：卡片排列
- 技能列表
- 联系方式

**技术栈**：HTML + CSS + JavaScript（单文件即可）

---

## 第一步：搭骨架（5 分钟）

### 发给 AI

```
帮我做一个个人作品集网站，要求：
1. 顶部导航栏：Home / Projects / Skills / Contact
2. Home 部分：大标题「Hi, I'm [你的名字]」+ 一句话介绍
3. 整体风格：极简白色背景，黑色字体，蓝色强调色
4. 用 HTML + CSS + JS 写在一个文件里
```

### 看效果

复制代码 → 新建 `portfolio.html` → 粘贴 → 右键 Open with Live Server

---

## 第二步：加内容（10 分钟）

### 加项目展示

```
帮我在 Projects 部分加 3 个示例项目卡片：
- 每个卡片有项目截图、标题、简介
- 鼠标悬停卡片微微上浮
- 三列排列，手机端一列
```

### 加技能列表

```
帮我在 Skills 部分加技能标签：
- 用彩色圆角标签展示
- 包含：HTML、CSS、JavaScript、Vue、React、Node.js
- 标签用蓝色渐变
```

### 加联系方式

```
帮我在 Contact 部分加：
- 邮箱（mailto 链接）
- GitHub 链接
- 一个简单的联系表单（姓名+消息+发送按钮）
```

---

## 第三步：润色（15 分钟）

### 加动画

```
帮我的页面加点平滑动画：
- 页面滚动时各区块淡入
- 导航栏滚动后变半透明
- 技能标签加载时依次弹出
```

### 响应式

```
让页面在手机上也能正常显示：
- 导航栏变成汉堡菜单
- 卡片从上到下排列
- 文字大小适应手机屏幕
```

### 暗色模式

```
给页面加一个暗色模式切换按钮，
点击可以在亮色和暗色之间切换。
```

---

## 第四步：部署上线（10 分钟）

### 方法：Netlify Drop

1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)
2. 把 `portfolio.html` 拖进去
3. Netlify 自动生成网址（如 `xxx.netlify.app`）
4. 全世界都能访问

### 自定义域名（可选）

告诉 AI：

```
我已经把网站部署到 Netlify 了（网址是 xxx.netlify.app），
我有一个自己的域名，帮我配一下。
```

---

## 第五步：持续迭代

上线只是开始，上线后你可以：

```
「帮我在作品集里加一个博客栏目」
「帮我在每个项目卡片下加一个 Demo 链接」
「帮我给网站加 Google Analytics 统计」
「帮我优化 SEO，让搜索引擎更容易搜到」
```

## Vibe Coding 项目检查清单

### 开始前

- [ ] 想清楚这个项目是干嘛的（一句话能说清楚）
- [ ] 列出 3-5 个核心功能（不需要多，能跑就行）
- [ ] 确定技术栈（新手选 HTML+CSS+JS）

### 开发中

- [ ] 先做最核心的功能（登录/列表/发帖...）
- [ ] 跑起来了再加下一个功能
- [ ] 每次改完就刷新看效果
- [ ] 报错了就把错误发给 AI
- [ ] 代码保存在文件夹里，别丢了

### 部署前

- [ ] 所有功能都跑通了一遍
- [ ] 手机和电脑都能正常看
- [ ] 没有明显的 bug

### 部署后

- [ ] 发链接给朋友测试
- [ ] 收集反馈 → 发给 AI 改
- [ ] 定期备份代码

## 从 Vibe Coding 到正式开发

Vibe Coding 不只是入门工具，也是专业开发者的效率倍增器。

| 阶段 | 怎么用 |
|------|--------|
| 零基础 | AI 写全部代码，你负责提需求 |
| 入门 | AI 写大部分，你开始理解代码结构 |
| 进阶 | AI 写样板代码，你写核心逻辑 |
| 专业 | AI 辅助补全、重构、debug、写测试 |
