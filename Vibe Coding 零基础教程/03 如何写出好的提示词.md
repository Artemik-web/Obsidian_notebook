# 03 如何写出好的提示词

> Vibe Coding 最核心的技能：让 AI 准确理解你的意思。

---

## 什么是提示词？

提示词 = 你发给 AI 的那段话。

**同样做一张名片，不同提示词效果天差地别：**

| 提示词 | 效果 |
|--------|------|
| 「做个网页」 | 随便给你一个，大概率不是你想要的 |
| 「做一个个人名片页面，白底居中卡片，圆形头像，三个技能标签」 | 基本是你想要的 |

---

## 好提示词的公式

```
场景 + 功能 + 风格 + 约束

场景：做什么用的
功能：具体有什么
风格：长什么样
约束：有什么限制
```

### 例子

```
❌ 差的：「做一个登录页面」

✅ 好的：「做一个校园社区登录页面。
      场景：大学生使用
      功能：手机号+验证码登录，加一个微信登录按钮
      风格：白色背景，蓝色主题，圆角输入框
      约束：只用一个 HTML 文件，适配手机端」
```

## 五个实用模板

### 模板 1：做一个新网页

```
帮我做一个 [网页类型]，要求：
1. [功能 1]
2. [功能 2]
3. [功能 3]
风格：[颜色/字体/布局]
技术：[HTML+CSS / React / Vue]
适配：[PC 端 / 手机端 / 都要]
```

### 模板 2：修改现有代码

```
这是我的代码（附代码）。
帮我把 [要改的地方] 改成 [想要的效果]。
```

### 模板 3：修复 Bug

```
这是我的代码（附代码），出现了这个错误（附报错信息）。
帮我看一下哪里有问题，怎么改。
```

### 模板 4：解释代码

```
帮我解释一下这段代码是干嘛的：
（附代码）
```

### 模板 5：加新功能

```
这是我的网页代码（附代码）。
帮我在 [位置] 加上一个 [新功能]。
```

## 十个高效果提示词

| 场景 | 提示词 |
|------|--------|
| 改进样式 | 「帮我把这个页面设计得更好看一些，加一些现代化的设计元素」 |
| 加动画 | 「给这个元素加一个淡入动画」 |
| 修布局 | 「这两个元素没对齐，帮我修一下」 |
| 加交互 | 「点击这个按钮后，弹出一个提示框」 |
| 响应式 | 「让这个页面在手机上也能正常显示」 |
| 性能 | 「这个页面加载太慢了，帮我优化」 |
| 代码整洁 | 「帮我把这段代码整理一下，让它更易读」 |
| 加注释 | 「给这段代码加上中文注释」 |
| 改配色 | 「把配色方案改成暗色主题」 |
| 部署 | 「帮我把这个项目部署到 GitHub Pages」 |

## 常见错误

### 1. 需求太模糊

```
❌ 「做一个好看的网站」
   → AI 随便给你一个，不一定是你想要的

✅ 「做一个个人博客，三栏布局，左边是文章列表，
   右边是标签云，白色背景，极简风」
```

### 2. 一次说太多

```
❌ 「我要一个带用户登录注册发帖评论点赞收藏关注
   私信推送通知管理后台数据大屏的社区网站...」

✅ 第一次：「做一个用户注册登录页面」
   第二次：「加上发帖功能」
   第三次：「加上评论功能」
   ...
```

### 3. 不提供上下文

```
❌ 「帮我改一下那个按钮」
   → AI 不知道你说的是哪个按钮

✅ 「这是完整代码（附代码），
   把第五行的 '提交' 按钮改成蓝色圆角」
```

## 进阶技巧

### 1. 给 AI 看参考

```
「我喜欢这个网站的设计风格（附链接或截图描述），
 帮我做一个类似的页面」
```

### 2. 限制技术栈

```
「只能用 HTML + CSS + 原生 JavaScript，不要用框架」
「用 React + TypeScript 写」
「用 Vue 3 + Element Plus 写」
```

### 3. 要求解释

```
「帮我写代码，并在每段关键代码旁边加注释解释为什么这么写」
```

### 4. 对比方案

```
「这个功能有两种实现方式，帮我各写一个版本，
 并告诉我各自的优缺点」
```
