# 01 工具安装与环境搭建

> 目标：30 分钟内把所有工具装好。

---

## 你要装什么

| 工具 | 必须？ | 用途 |
|------|--------|------|
| VS Code | ✅ 必须 | 写代码的编辑器 |
| Node.js | ✅ 必须 | 让电脑能运行 JavaScript |
| Cursor（推荐） | 推荐 | 内置 AI 的编辑器 |
| Claude / ChatGPT | ✅ 必须 | AI 助手 |

---

## 第一步：安装 VS Code

1. 打开 [code.visualstudio.com](https://code.visualstudio.com)
2. 点击 **Download**（选择你的系统：Windows/Mac）
3. 下载完成后双击安装
4. 安装时**全部默认选项**，一路下一步

### 安装中文插件

1. 打开 VS Code
2. 左侧点击扩展图标（四个方块）
3. 搜索 `Chinese`
4. 安装 **Chinese (Simplified) Language Pack**
5. 重启 VS Code

---

## 第二步：安装 Node.js

1. 打开 [nodejs.org](https://nodejs.org)
2. 下载 **LTS 版本**（长期支持版，更稳定）
3. 双击安装，全部默认选项，一路下一步

### 验证安装

打开终端（VS Code 里按 `` Ctrl + ` ``）：

```bash
node --version   # 你应该看到 v18.x.x 或 v20.x.x
npm --version    # 你应该看到 9.x.x 或 10.x.x
```

如果有版本号出来，说明安装成功 ✅

---

## 第三步：选择 AI 工具

### 方案 A：Cursor（推荐新手）

[Cursor](https://cursor.com) 是一个内置了 Claude 的代码编辑器。

**优点**：
- 开箱即用，不需要配插件
- 选中代码就能让 AI 改
- 支持中文对话

**安装**：
1. 下载 Cursor → [cursor.com](https://cursor.com)
2. 安装后注册账号（用 GitHub 账号登录）
3. 免费版每月有 2000 次 AI 请求

### 方案 B：VS Code + Claude（推荐）

如果你已装了 VS Code，可以装 Claude 插件：

1. 打开 VS Code 扩展
2. 搜索 `Claude Code`
3. 安装后按提示登录 Anthropic 账号

### 方案 C：在浏览器用 Claude/ChatGPT

- 打开 [claude.ai](https://claude.ai) 或 [chat.openai.com](https://chat.openai.com)
- 直接在聊天框里描述需求
- AI 给你代码，你复制到 VS Code

---

## 第四步：创建一个项目文件夹

### 方法 1：在 VS Code 里创建

1. 打开 VS Code
2. 文件 → 打开文件夹
3. 在桌面创建一个新文件夹，比如 `my-first-project`
4. 点击选择文件夹

### 方法 2：手动创建

1. 桌面右键 → 新建文件夹
2. 命名为 `my-first-project`
3. 在 VS Code 里打开这个文件夹

---

## 第五步：创建第一个文件

1. VS Code 左侧文件列表里，右键 → 新建文件
2. 命名为 `index.html`
3. 输入以下内容：

```html
<!DOCTYPE html>
<html>
<head>
    <title>我的第一个网页</title>
</head>
<body>
    <h1>Hello, Vibe Coding!</h1>
</body>
</html>
```

4. 右键文件 → **Open with Live Server**（如果没有，先装 Live Server 插件）
5. 浏览器会自动打开，你应该能看到一行大字

---

## 验证：环境就绪

你能在浏览器看到 `Hello, Vibe Coding!` → ✅ 环境搭建完成！

## 常见问题

**Q: Node.js 安装后命令行找不到 node？**
> 重启终端，或者重启电脑。

**Q: Cursor 和 VS Code 选哪个？**
> 新手选 Cursor（简单），有基础的选 VS Code（灵活）。

**Q: AI 工具收费吗？**
> Claude/ChatGPT 有免费额度，Cursor 每月免费 2000 次请求。
