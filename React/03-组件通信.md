# React 组件通信

React 组件之间通信有多种方式，根据场景选：

## 1. 父 → 子

### props 最常用

```jsx
// 父组件
function Parent() {
  const [name, setName] = useState('zhangsan');
  return <Child name={name} />;
}

// 子组件
function Child(props) {
  return <div>name: {props.name}</div>;
}

// 默认值
function Child({ name = 'default' }) {
  return <div>{name}</div>;
}
```

## 2. 子 → 父

### 通过回调函数

```jsx
// 父组件
function Parent() {
  const [count, setCount] = useState(0);

  // 传给子组件一个回调
  const handleChildClick = (value) => {
    setCount(value);
  };

  return <Child onChildClick={handleChildClick} />;
}

// 子组件
function Child({ onChildClick }) {
  return <button onClick={() => onChildClick(123)}>传给父</button>;
}
```

## 3. 兄弟组件通信

### 方法一：通过父组件中转

兄 A → 父 → 兄 B，父做中转。

### 方法二：状态管理工具（推荐大项目）

用 Redux / Zustand / Jotai / Recoil，兄弟都从状态管理拿数据，改状态一起更新。

## 4. 跨层级通信

### Context API（推荐，不用第三方库）

```jsx
// 顶层创建 Context
const ThemeContext = createContext();

function App() {
  return (
    <ThemeContext.Provider value="dark">
      <Toolbar />
    </ThemeContext.Provider>
  );
}

// 深层组件拿
function ThemedButton() {
  const theme = useContext(ThemeContext);
  return <button style={{ background: theme }}>按钮</button>;
}
```

优点：不用一层层传 props，深层组件直接拿，方便。
缺点：数据变了，所有用到 context 的组件都会重新渲染，优化不好性能有问题。

### 状态管理工具（推荐大项目）

Zustand 现在最受欢迎，轻量简单：

```js
// store.js
import { create } from 'zustand';

const useStore = create((set) => ({
  count: 0,
  increase: () => set(state => ({ count: state.count + 1 })),
}));

// 组件里用
function Counter() {
  const count = useStore(state => state.count);
  const increase = useStore(state => state.increase);
  return <button onClick={increase}>{count}</button>;
}
```

## 5. 其他通信方式

### ref 获取组件实例

父组件拿到子组件实例调用方法：

```jsx
// 子组件
function Child(props, ref) {
  const inputRef = useRef();

  useImperativeHandle(ref, () => ({
    focus: () => {
      inputRef.current.focus();
    }
  }));

  return <input ref={inputRef} />;
}

const Child = forwardRef(Child);
export default Child;

// 父组件
function Parent() {
  const childRef = useRef(null);

  const handleClick = () => {
    childRef.current.focus();
  };

  return (
    <div>
      <Child ref={childRef} />
      <button onClick={handleClick}>focus</button>
    </div>
  );
}
```

### 发布订阅模式

自己写简单：

```js
// eventBus.js
class EventBus {
  constructor() {
    this.events = {};
  }

  on(eventName, callback) {
    if (!this.events[eventName]) {
      this.events[eventName] = [];
    }
    this.events[eventName].push(callback);
  }

  emit(eventName, data) {
    if (this.events[eventName]) {
      this.events[eventName].forEach(cb => cb(data));
    }
  }

  off(eventName, callback) {
    if (this.events[eventName]) {
      this.events[eventName] = this.events[eventName].filter(cb => cb !== callback);
    }
  }
}

export default new EventBus();
```

使用：
```jsx
// 组件A
import bus from './eventBus';

useEffect(() => {
  const handleData = (data) => console.log(data);
  bus.on('data-change', handleData);
  return () => {
    bus.off('data-change', handleData);
  };
}, []);

// 组件B
import bus from './eventBus';

bus.emit('data-change', { name: 'zhangsan' });
```

现在项目不太推荐，有 context 或者 zustand 更干净。

## 总结通信方式对照表

| 场景 | 方式 |
|------|------|
| 父 → 子 | props |
| 子 → 父 | 回调函数 |
| 兄弟 | 父中转 / 状态管理 |
| 跨层级 | Context / 状态管理 |
| 复杂场景 | Zustand / Redux |

项目推荐：小项目 context 够了，中大型项目上 Zustand 简单轻量，比 Redux 少很多模板代码。
