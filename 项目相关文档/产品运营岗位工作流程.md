# 产品运营岗位工作流程

> **岗位负责人**：方菲
> **岗位目标**：通过内容运营和活动运营，让更多用户知道并使用南青年社区

---

## 一、岗位定义

产品运营负责南青年社区的内容产出、用户增长和日常系统维护，是连接产品和用户的桥梁。

---

## 二、核心任务

### 任务 1：公众号推文

- **频率**：一周 1-2 篇
- **内容方向**：校园生活、活动通知、团队故事（团建专栏）、用户故事
- **发布流程**：选题 → 写稿 → 排版 → 发布 → 转发朋友圈/群

### 任务 2：校园采访视频

- **频率**：一周 1 个
- **内容方向**：校园随机采访、同学使用感受、活动记录
- **发布渠道**：抖音 + 视频号
- **流程**：策划话题 → 拍摄 → 剪辑 → 发布

### 任务 3：日常活动创建与开展

- **线上活动**：话题讨论、投票、征集、抽奖
- **线下活动**：摆摊、社团合作、推广
- **每月至少 1 次活动**，活动后出总结

### 任务 4：日常系统运营

| 工作项 | 说明 |
|--------|------|
| 更新到梦空间活动列表 | 社区内的活动信息及时同步到到梦空间 |
| 审核认证 | 用户注册认证审核，身份信息核实 |
| 举报处理 | 收到举报及时审核处理，违规内容删除/封号 |
| 内容巡查 | 定期检查社区内容，清理违规信息 |

### 任务 5：产品需求提议

- 日常运营中发现用户痛点或产品不足
- 整理成需求文档提交给涂梓峰
- **格式**：`需求名称 + 功能描述 + 为什么做 + 优先级`

---

## 三、工作节奏

```
每日：
  - 查看系统数据（注册用户、日活、发帖量）
  - 处理审核/举报
  - 回复用户反馈

每周：
  - 完成 1-2 篇公众号推文
  - 完成 1 个校园采访视频
  - 更新到梦空间活动列表
  - 周日周会汇报本周数据 + 下周计划

每月：
  - 至少 1 次活动
  - 提交产品需求提议
```
