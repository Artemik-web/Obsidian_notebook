# 产品运营岗位工作流程

> 面向：方菲 + 运营组成员
> 目的：清楚每天该干什么、每个东西怎么做

---

## 一、岗位职责总览

```
产品运营负责人（方菲）
├── 内容运营
│   ├── 公众号：推文撰写、排版、发布
│   ├── 抖音：视频策划、拍摄、剪辑、发布
│   └── 小红书：笔记撰写、发布
├── 用户增长
│   ├── 线上推广：微信群、朋友圈、邀请机制
│   ├── 线下推广：海报、摆摊、社团合作
│   └── 用户反馈：收集问题、整理需求
└── 产品支持
    ├── 种子内容填充
    ├── 社区规则/公告撰写
    └── 帮助中心/FAQ
```

---

## 二、日常工作流程

### 每日必做

```
到岗后（或线上打卡）
│
├── ① 查看昨日数据 → 记录到数据表
│   ├── 公众号：阅读量、新增关注
│   ├── 抖音：播放量、点赞、新增粉丝
│   └── 产品：注册用户数、日活
│
├── ② 回复用户反馈 → 整理到反馈表
│
├── ③ 检查内容发布计划 → 今天该发什么
│
└── ④ 站会汇报 → 三句话
    ├── 昨天做了什么
    ├── 今天要做什么
    └── 有没有卡住的问题
```

### 隔日站会（周一三五 21:00）

```
每人 2 分钟，说三句：
1. 上次站会后做了什么
2. 下次站会前要做什么  
3. 有没有卡住的问题
```

### 周日周会

```
会前准备：
- 整理本周数据（公众号阅读量/抖音播放量/用户数）
- 列出下周要发的所有内容

会上汇报：
- 本周做了什么、效果如何
- 下周计划
- 需要 artemik 协调的问题
```

## 三、各渠道工作流程

### 公众号运营

#### 内容规划

```
每周规划（周日定下周）
├── 日常推文 x 3-4 篇
│   ├── 校园生活类（食堂、穿搭、探店）
│   ├── 学习干货类（复习资料、考证攻略）
│   ├── 活动通知类（社区活动、福利）
│   └── 用户故事类（访谈、投稿）
│
└── 团建专栏 x 1 篇
    ├── 记录团队活动（团建、聚餐、会议）
    ├── 展示成员风采（介绍团队里的人）
    └── 项目进展（最近做了什么、上线进度）
```

#### 发布流程

```
选题 → 编写 → 排版 → 审核 → 发布 → 转发

选题：周日确定下周所有选题
编写：提前 2 天写好初稿
排版：用秀米/135编辑器，保持统一风格
审核：发给 artemik 看一眼（重要推文）
发布：固定时间（建议中午 12:00 或晚上 18:00）
转发：发到朋友圈 + 校内微信群
```

#### 团建专栏特别说明

> 这是新增的重点任务。目的是让大家看到团队在做事情，增强归属感。

```
第一篇方向参考：
- 团队最近在做什么？（上线准备过程记录）
- 成员介绍（每人一小段+照片）
- 项目背后的故事（为什么做这个社区）

频率：每周至少 1 篇
发布日：建议固定在每周四/五
```

---

### 抖音运营

#### 视频生产流程

```
策划 → 拍摄 → 剪辑 → 审核 → 发布 → 数据跟踪

策划（提前 3 天）：
- 确定视频主题
- 写脚本（30-60秒）
- 准备拍摄道具/场地

拍摄（提前 2 天）：
- 手机拍摄即可，横屏 16:9
- 注意光线和收音

剪辑（提前 1 天）：
- 用剪映，加字幕
- 加背景音乐
- 封面图要吸引人

发布：固定时间（建议 12:00 或 18:00）
跟踪：发布后 1 小时、24 小时分别看数据
```

#### 内容方向

| 类型 | 举例 | 频次 |
|------|------|------|
| 产品功能介绍 | 南青年社区怎么用 | 每周 1 条 |
| 校园日常 | 食堂、操场、图书馆 | 每周 1 条 |
| 团队日常 | 研发花絮、开会、团建 | 每周 1 条 |
| 用户故事 | 同学采访、使用感受 | 每两周 1 条 |

---

### 线下推广

#### 活动准备清单

```
活动前 1 周：
□ 确定活动时间/地点
□ 物料清单确认（海报、传单、易拉宝、二维码立牌、小礼品）
□ 人员安排（谁守摊位、谁发传单、谁拍照）

活动前 1 天：
□ 物料全部到位
□ 天气确认（室外活动）
□ 群里通知所有参与人员

活动当天：
□ 提前 30 分钟到场布置
□ 拍照/拍视频记录
□ 引导用户扫码注册
□ 活动结束后收拾场地

活动后 1 天：
□ 整理活动照片（发公众号/抖音素材）
□ 统计当天注册用户数
□ 活动复盘
```

## 四、数据跟踪

### 每天要记什么

| 渠道 | 指标 | 记录频率 |
|------|------|----------|
| 公众号 | 阅读量、新增关注 | 每日 |
| 抖音 | 播放量、点赞、评论、新增粉丝 | 每日 |
| 产品 | 注册用户数、日活、发帖数 | 每日 |
| 线下 | 扫码注册数、传单发出数 | 活动日 |

### 数据用来干嘛

```
数据价值：
- 发现什么内容用户喜欢 → 多做
- 什么内容没人看 → 换方向
- 用户增长慢了 → 加大推广
- 用户活跃低了 → 搞活动/话题

每周日周会前整理成周报：

|------|----------|----------|------|------|
| 公众号 | | | | |
| 抖音 | | | | |
| 产品用户 | | | | |
```

## 五、跨部门协作

### 需要找涂梓峰的时候

```
1. 产品需要新功能（如邀请奖励机制）
   → 写好需求文档，交给涂梓峰排期

2. 用户反馈了 bug
   → 截图 + 描述，发给涂梓峰

3. 社区内容需要审核/处理
   → 后台管理操作（删帖、封号等）
```

### 需要找 artemik 的时候

```
1. 需要预算（物料、KOL合作等）
2. 需要决策（方向、优先级）
3. 遇到自己搞不定的问题
```
