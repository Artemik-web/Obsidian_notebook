## 一、岗位定义

---

## 二、核心任务

### 任务 1：产品需求定制开发

**来源**：产品运营（方菲）提出的需求文档

**流程**：

```
收到需求 → 评估可行性 → 任务拆分 → 分配开发 → 测试 → 上线

需求文档格式（方菲提供）：
  需求名称：___________
  功能描述：___________
  为什么要做：_________
  优先级：P0/P1/P2
```

**P0 = 不做系统用不了** → 立即处理
**P1 = 重要但不紧急** → 排入本周迭代
**P2 = 有了更好** → 排入下期

### 任务 2：日常系统更新

**研发组自己发现的问题或可优化的地方，主动更新系统，不等需求。**

| 类型 | 举例 | 谁发现 |
|------|------|--------|
| Bug 修复 | 页面报错、接口超时、数据异常 | 任何人 |
| 性能优化 | 加载速度慢、数据库查询慢 | 研发组 |
| 安全加固 | 权限漏洞、XSS、SQL注入 | 研发组 |
| 体验优化 | 按钮位置不对、文案错误 | 任何人 |
| 技术升级 | 依赖版本更新、框架升级 | 研发组 |

**处理方式**：
- 小问题 → 直接改，群里说一声
- 大改动 → 群里讨论后再改
