## 二、开发工作流程

### 完整开发周期

```
需求确认 → 任务拆分 → 开发 → 自测 → 合并 → 联调 → 上线

每一步往下走 ↓
```

#### 1️⃣ 需求确认

```
谁来：涂梓峰 + artemik/方菲

做什么：
- 方菲提出需求（书面，不是口头）
- 涂梓峰评估：能不能做、要多久
- 确认优先级和排期

交付物：需求文档
格式：
  ## 需求名称
  - 功能描述：
  - 优先级：P0/P1/P2
  - 期望时间：
  - 备注：

P0 = 不上线就完蛋（如注册登录）
P1 = 重要但可以等几天（如个人中心）
P2 = 有了更好（如动画效果）
```

#### 2️⃣ 任务拆分

```
谁来：涂梓峰

做什么：
- 把需求拆成可执行的具体任务
- 分配给对应的人
- 确定截止时间

示例：
  需求：注册登录功能
  拆分：
  - 前端：注册页面UI → 周腾龙（2天）
  - 前端：登录页面UI → 周腾龙（1天）
  - 后端：注册接口开发 → 林长浦（2天）
  - 后端：登录接口开发 → 林长浦（1天）
  - 数据库：用户表创建 → 徐泽峰（0.5天）
```

#### 3️⃣ 开发

```
谁来：被分配任务的人

做什么：
- 按照任务要求开发
- 代码写完后自己先测试
- 确保基本功能能跑通再提交

自测清单：
□ 功能能正常使用
□ 报错时有提示
□ 页面没有明显bug
□ 接口返回正确
```

#### 4️⃣ 代码合并

```
谁来：开发者提交 → 涂梓峰审核

流程：
1. 开发者提交代码到功能分支
2. 在群里@涂梓峰 说"代码写好了"
3. 涂梓峰 review → 没问题就合并到主分支
4. 有问题 → 打回修改

注意：
- 不要憋好几天才提交，每天至少提交一次
- 提交信息格式：type(模块): 描述
  例：feat(登录): 新增手机验证码登录
  例：fix(帖子): 修复图片上传失败
```

#### 5️⃣ 联调测试

```
谁来：前端+后端一起

做什么：
- 前端对接后端真实接口
- 跑通完整流程（注册→登录→发帖→评论→删除）
- 发现问题立即修

验收标准：
- 所有 P0 功能完整可用
- 没有阻断性问题
```

#### 6️⃣ 上线发布

```
谁来：周腾龙（涂梓峰审核）

流程：
1. 代码冻结（不再新增功能，只修bug）
2. 回归测试（所有功能跑一遍）
3. 服务器部署（林长浦）
4. 数据初始化（徐泽峰）
5. 正式发布
6. 线上验证（发布后观察30分钟）

回滚预案：
- 如果上线后出现严重问题，立即回滚到上一个版本
- 5分钟内必须完成回滚
```

## 三、日常工作流程

### 每日必做

```
到岗/上线后
│
├── ① 查看任务列表 → 今天要做什么
│   （参考任务卡片或群里通知）
│
├── ② 开始开发/测试
│
├── ③ 有进展 → 群里更新一下
│   （可选，但建议随手说一句）
│
└── ④ 站会汇报 → 三句话
```

### 隔日站会（周一三五 21:00）

```
每人 2 分钟，说三句：
1. 上次站会后做了什么
2. 下次站会前要做什么
3. 有没有卡住的问题（需要谁帮忙）
```

### 周日周会

```
会前：
- 确认自己本周的任务完成情况
- 想好下周要做什么

会上：
- 汇报本周完成的任务
- 说明未完成的原因
- 提出需要帮助的问题
- 接下周任务

会后：
- 涂梓峰确认每个人的任务卡片
- 任务卡片发到群里
```

## 四、Bug 处理流程

### Bug 分级

| 级别 | 定义 | 响应时间 | 修复时间 |
|------|------|----------|----------|
| 🔴 P0 | 系统不能用（用户无法登录、页面白屏） | 立即 | 24小时内 |
| 🟡 P1 | 功能异常但不影响核心（评论点不了、图片加载慢） | 当天 | 下次发版 |
| 🟢 P2 | 体验问题（按钮位置不对、颜色不好看） | 排期 | 随下次迭代 |

### 处理流程

```
发现 Bug → 报告 → 确认 → 修复 → 验证 → 关闭

谁来报告：任何人（方菲/artemik/测试）
报告格式：
  Bug：用户注册后收不到验证码
  ﹣ 复现步骤：1.输入手机号 2.点击获取验证码 3.没有收到短信
  ﹣ 环境：iOS微信浏览器
  ﹣ 严重程度：P1
  ﹣ 截图/录屏：有

谁来确认：涂梓峰
谁来修复：分配给对应的人
谁来验证：报告 Bug 的人
```

## 五、技术分享制度

### 频率和形式

```
频率：每两周 1 次
时长：20-30 分钟
时间：周日周会后
形式：PPT 或现场演示
```

### 内容方向

| 类型 | 举例 |
|------|------|
| 技术知识点 | Vue3响应式原理、TypeScript高级用法 |
| 项目经验 | 踩坑记录、性能优化实战 |
| 新技术调研 | 对比某个轮子、新框架试用 |
| 工具推荐 | 好用的小工具、提高效率的技巧 |

### 排期安排（涂梓峰负责）

```
5月12日前排出第一轮分享计划，示例：

第一周：涂梓峰 — Vue3响应式原理
第二周：周腾龙 — Vite配置实战
第三周：林长浦 — Docker部署入门
第四周：徐泽峰 — SQL优化技巧
第五周：周永刚 — Nginx配置与安全
```
