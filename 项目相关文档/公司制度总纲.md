## 三、工作节奏

```
周一上午   部门例会（各自部门内部）
周日下午   全体周会（全员参加）

全体周会议程：
1. 每人汇报本周完成情况（2分钟/人）
2. 遇到的问题讨论
3. 下周任务分配
4. 更新进度文档
```

## 六、沟通规则

1. **日常沟通**：部门内部微信群
2. **跨部门协调**：找对应负责人，不要越级
3. **紧急问题**：直接打电话，不要等微信回复
4. **问题上报**：自己解决不了的，24小时内上报给上级
5. **周报**：每周日例会前，每人更新自己的完成情况
