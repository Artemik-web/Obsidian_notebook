# Linux 服务器常用命令

日常开发部署、排查问题常用命令，整理前端开发常用的，够用就行。

---

## 文件目录操作

```bash
pwd # 查看当前所在目录
ls # 列出文件
ls -l # 详细列表
ls -a # 显示隐藏文件
cd /path/to/xxx # 切换目录
cd ~ # 回用户家目录
cd - # 回到上次目录
mkdir dirname # 创建目录
mkdir -p a/b/c # 递归创建多级目录
rm filename # 删除文件
rm -rf dirname # 递归删除目录，强制删除（小心用！）
cp source target # 复制
cp -r source target # 复制目录
mv source target # 移动/重命名
find /path -name "*.js" # 找文件
tree # 树形显示目录结构（需要安装）
```

---

## 文件查看编辑

```bash
cat file # 输出整个文件内容
cat | grep keyword # 搜索关键词
more file # 分页看，空格翻页
less file # 更好分页，可以上下翻，q退出（推荐用less）
tail -f file # 实时看文件末尾，看日志常用
tail -n 100 file # 看最后100行
head -n 10 file # 看开头10行
grep keyword file # 在文件找关键词，输出行
grep -r keyword ./ # 递归整个目录找关键词
grep -i keyword file # 忽略大小写
vim file # vim编辑，不会用还是用nano吧
nano file # 简单编辑器
echo "content" > file # 写入内容到文件，覆盖
echo "content" >> file # 追加内容到文件末尾
```

## 权限管理

```bash
chmod +x script.sh # 添加执行权限
chmod 755 file # rwxr-xr-x
chmod 644 file # rw-r--r--
# 数字含义：r=4 w=2 x=1，三位分别是：用户、组、其他
chown user:group file # 修改文件所有者
sudo # 用root权限执行命令
su - # 切换到root
su username # 切换用户
```

## 进程管理

```bash
ps aux # 查看所有进程
ps aux | grep nginx # 找nginx进程
top # 动态看进程CPU内存占用，q退出
htop # 更好看的top，需要安装
kill pid # 杀死进程
kill -9 pid # 强制杀死
killall name # 根据名字杀进程
pkill name # 根据名字杀进程
```

## 查看系统信息

```bash
uname -a # 内核版本系统信息
lsb_release -a # 看发行版版本
cat /etc/os-release # 看系统信息
free -h # 查看内存使用，-h 人性化显示单位
df -h # 查看磁盘各分区使用
du -sh # 查看当前目录大小
du -sh node_modules # 看目录大小
uptime # 看运行时间，负载
whoami # 当前用户名
hostname # 主机名
date # 看时间
```

## 网络相关

```bash
ifconfig # 看网卡信息（旧命令，现在用ip addr）
ip addr # 看ip地址
netstat -tulpn # 看端口监听（需要net-tools）
netstat -tulpn | grep :80 # 看80端口谁在监听
ss -tulpn # 和上面一样，新版推荐用ss
lsof -i :80 # 看哪个进程占了80端口
curl https://example.com # 请求url，输出内容
curl -i https://example.com # 看响应头
wget https://example.com/file.zip # 下载文件
ping example.com # ping看通不通
traceroute example.com # 路由追踪看哪里断了
nslookup example.com # DNS查询
```

## 压缩解压

```bash
# tar.gz
tar -zcvf archive.tar.gz dir/ # 压缩
tar -zxvf archive.tar.gz # 解压
tar -ztvf archive.tar.gz # 看压缩包内容不解压

# zip
zip -r archive.zip dir # 压缩
unzip archive.zip # 解压

# gz
gzip file # 压缩
gunzip file.gz # 解压
```

## 链接

```bash
ln -s /real/path /link/path # 创建软链接（类似快捷方式）
# 例子：node版本切换，把当前版本链接到全局
ln -s /opt/node-v18/bin/node /usr/local/bin/node
# 删除软链接，不要加/
rm /link/path
```

## 远程登录传输

```bash
ssh user@host # ssh登录
ssh -p 22 user@host # 指定端口
scp file user@host:/path # 本地文件传到服务器
scp user@host:/path/file ./ # 服务器文件拉到本地
scp -P port file user@host:/path # 指定端口
```

## 后台运行

让命令在后台运行，关闭ssh也不中断：

```bash
# 方法1：nohup，输出放nohup.out
nohup npm run start &

# 方法2：screen 虚拟终端（推荐）
screen # 新开一个
screen -S name # 创建指定名字
screen -ls # 列出所有
screen -r id # 回到会话
#  detach：Ctrl+A+D  detach退出，保持后台
# kill：Ctrl+A+K 杀死会话

# 方法3：tmux 和screen类似，更强大
```

## Docker 常用

```bash
docker ps # 看运行容器
docker ps -a # 看所有
docker logs container-id # 看日志
docker logs -f container-id # 实时看日志
docker exec -it container-id /bin/bash # 进容器
docker restart container-id # 重启容器
docker-compose pull # 拉最新镜像
docker-compose up -d # 启动
docker-compose down # 停止
```

## Nginx 常用

```bash
nginx -t # 测试配置对不对
nginx -s reload # 重新加载配置，不重启
systemctl restart nginx # 重启nginx
systemctl status nginx # 看状态
```

## 常用排查问题

1. **网站打不开排查：**
   ```bash
   curl http://localhost:80 # 本地试试能访问不
   ss -tulpn | grep :80 # 看看nginx有没有起来，端口对不对
   nginx -t # 看看配置错了没
   tail -f /var/log/nginx/error.log # 看看nginx报错
   df -h # 看看磁盘满了没
   ```

2. **服务器卡：**
   ```bash
   top # 看哪个进程占CPU内存多
   free -h # 看看是不是内存爆了
   ```

3. **文件找不到：**
   ```bash
   find / -name "filename" # 全局找文件
   ```
